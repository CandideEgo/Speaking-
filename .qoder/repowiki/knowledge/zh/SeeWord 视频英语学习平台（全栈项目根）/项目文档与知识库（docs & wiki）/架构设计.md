文档按主题分层组织，分为两个互补目录：
- `docs/`：面向当前迭代的临时与过程性文档，包括 `adr/`（编号化 ADR，按 0001..0012 顺序管理，每个文件遵循 Title/Status/Context/Decision/Consequences 固定结构）、`plans/`（分阶段落地计划如 REDESIGN-2026-07、PIPELINE-FLOW 等）、`design/`、`frontend/`、`operations/`、`reports/`、`progress/`、`mockups/`（含可运行的 HTML/CSS 原型）和顶层 `GLOSSARY.md`。
- `wiki/`：长期工程知识库，按 `INDEX.md` 导航，划分为 `architecture/`（视频管线、认证、前端架构等持久技术文档）、`guides/`（setup、testing 等操作指南）、`problems/`（问题复盘）。
两目录通过 GLOSSARY 与 ADR README 相互引用，形成「短期决策 + 长期知识」的双层结构，无代码依赖，纯 Markdown 驱动。
