采用 Next.js 16 App Router 作为路由与页面组织核心，通过 `(admin)`、`(landing)`、`(main)` 等 route group 划分不同业务域，每个组内以 `layout.tsx` 定义共享布局（如 admin shell、主站布局），页面按功能目录拆分（browse、watch、profile、pricing、admin 等）。状态管理统一使用 Zustand store（`src/stores/`），包括 authStore、feedStore、planStore、watchStore、vocabularyStore 等，所有认证状态集中在 `authStore.ts`，并通过 `AuthInitializer` 组件在根布局中初始化。API 层通过 `lib/api.ts` 暴露统一的 `api()` 函数和 `mediaUrl()` 代理工具，底层由 `createApiClient` 封装，支持 JWT 自动刷新与错误处理。组件按职责分层：`components/ui` 为原子 UI 组件，`components/common` 为通用业务组件（主题、模态框、骨架屏等），其余按功能域（admin、auth、landing、video、subtitle 等）组织。全局样式通过 Tailwind CSS v4 + PostCSS 构建，主题切换由 `ThemeProvider` 驱动。Dockerfile 与 Dockerfile.prod 分别用于开发与生产镜像构建，Playwright 负责跨浏览器 e2e 测试。
