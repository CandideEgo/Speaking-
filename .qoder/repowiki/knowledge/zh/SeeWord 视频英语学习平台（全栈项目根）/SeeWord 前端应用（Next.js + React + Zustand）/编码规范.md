- Zustand store 统一放在 `src/stores/` 目录下，每个 store 导出一个 `useXxxStore` hook，通过 `create()` 创建并暴露 state 与 actions。
- API 调用统一通过 `lib/api.ts` 导出的 `api()` 函数发起，禁止直接 `fetch` 调用后端接口，确保统一的错误处理、token 注入与刷新机制。
- 媒体 URL 必须通过 `mediaUrl()` 包装，自动对已知 CDN 主机名走后端 `/media/proxy` 代理，避免热链保护与混合内容问题。
- 认证相关逻辑集中通过 `authStore.ts` 管理，禁止在组件中直接读写 localStorage 中的 token，统一通过 `getToken()` 获取当前 token。
- 页面路由遵循 Next.js App Router 约定，使用 `(group)` 命名空间划分业务域，每个组内通过 `layout.tsx` 定义共享布局，页面文件命名为 `page.tsx`。
- 组件按功能域分包（admin、auth、common、ui、landing、video 等），原子 UI 组件放在 `components/ui/`，业务组件放在对应领域目录，避免深层嵌套。
