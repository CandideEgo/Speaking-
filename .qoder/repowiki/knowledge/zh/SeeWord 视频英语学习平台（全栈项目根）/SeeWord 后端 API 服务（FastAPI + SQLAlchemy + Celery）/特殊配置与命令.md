运行需准备 `.env`（参考 `.env.example`），包含数据库 URL、Redis、JWT Secret、OpenAI/阿里云密钥等；开发环境默认连接本地 PostgreSQL `seeword_dev` 与 Redis；GPU 转录需单独启动 GPU Worker（`scripts/start_gpu_worker.py` + `.env.gpu-worker`），消费 `transcription_gpu` 队列；数据库迁移通过 Alembic（`alembic.ini` 指向 `migrations/versions/`）；测试使用 pytest（`pytest.ini` 配置异步模式与超时）。
