模块采用典型的 FastAPI 分层架构：
- `app/main.py` 通过 `create_app()` 构建应用，集中注册异常处理器（AppError/HTTPException/RateLimitExceeded/AIServiceError）、中间件（请求 ID、日志、安全头、CORS）、Prometheus 指标暴露以及所有 `/api/v1` 路由。
- `app/api/v1/` 按业务域拆分子模块（auth、users、videos、payments、learning、shadowing 等），每个子模块定义独立 `APIRouter`，由 main 统一挂载。
- `app/core/` 提供共享基础设施：配置（`pydantic_settings.Settings` 单例）、数据库（asyncpg + SQLAlchemy 2.0）、Redis 客户端、JWT 安全、限流（slowapi）、错误模型与结构化日志（structlog）。
- `app/models/` 为 SQLAlchemy ORM 模型，依赖顺序导入确保关系解析；`app/schemas/` 使用 Pydantic v2 定义请求/响应 DTO。
- `app/services/` 封装领域逻辑（AI、支付、OSS、视频处理、搜索、推荐等），对外暴露纯函数式接口，被 API 层调用。
- `app/tasks/` 基于 Celery + Redis broker，定义多队列拓扑（默认 `celery` 队列 + 专用 `transcription_gpu` 队列给远程 GPU 工作进程），并注册周期性 Beat 任务（订单过期、评分计算、Pro 降级等）。
- 依赖方向单向：API → services → models/core，tasks 仅依赖 core 和 models，不反向依赖 API。
