- API 路由文件以 `APIRouter(prefix='/xxx', tags=['xxx'])` 组织，统一在 `main.py` 中通过 `app.include_router(router, prefix='/api/v1')` 挂载。
- 配置全部集中在 `app.core.config.Settings`（pydantic_settings），通过 `@lru_cache` 的 `get_settings()` 获取单例，生产环境强制校验必填字段。
- 异常统一继承 `AppError` 并返回 `{code, message, detail?}` 信封格式，HTTP 异常与 Pydantic 422 均被全局异常处理器转换为同一结构。
- 数据库操作使用 SQLAlchemy 2.0 异步语法（`AsyncSession` + `select(...).execute()`），通过 `Depends(get_db)` 注入会话。
- 敏感操作通过 `@rate_limit('N/timeunit')` 装饰器配合 slowapi 进行限流，Redis 键前缀规范如 `sms:cooldown:{phone}:{purpose}`。
- Celery 任务按功能拆分到独立文件（order_tasks、scoring_tasks、video_processing 等），通过 `task_routes` 将特定任务路由到专用队列（如 `transcription_gpu`）。
