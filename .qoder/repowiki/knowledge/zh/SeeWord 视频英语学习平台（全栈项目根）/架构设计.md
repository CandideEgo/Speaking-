根目录作为编排层，将三个子模块串联为完整产品：
- docker-compose.yml / .dev / .prod 三套 compose 文件分别定义开发（DB+Redis+backend+celery+frontend）、生产（Nginx+Gunicorn/Next/Celery）环境的服务依赖与端口映射。
- backend 通过 DATABASE_URL 和 REDIS_URL 连接共享的 PostgreSQL 16 与 Redis 7；celery worker 与 backend 共享同一数据库与消息队列。
- frontend 通过 Next.js dev server（3000 端口）在开发时直接调用 backend API（8000 端口），生产时由 Nginx 统一反代到 Gunicorn 与 Next.js。
- nginx.conf / nginx.ssl.conf 提供 HTTP/HTTPS 入口，将 /api 路由转发至后端，静态资源与 SSR 请求转发至前端。
- docs 子模块存放架构决策、API 参考、设计 token 等跨前后端共同遵循的契约文档，是前后端协作的唯一真相来源。
