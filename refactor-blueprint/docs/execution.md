# 后端重构实施包

本页定义实施顺序与边界；已落地范围和验证统一见[实施记录](implementation.md)，不能把整包目标当成已实现。先读仓库规则、本目录 README 和 [审查结论](review.md)。用户允许舍弃工作区 V2 试做，不要求沿用；恢复/清理应按已审范围执行，不能扩大到无关改动或数据库。每个实施包交付可运行切片，禁止一次性重写或放宽检查基线。

目标依据与最终范围统一见[目标框架 §0](architecture.md)。2026-11-05 起按下列 V2 学习闭环推进；B01–B06 是职责/任务包，不再要求 B02 所有旧模块整理结束才开始 B03/B04。每个切片只以前置契约、受影响消费者和实际数据状态为门；未核实的部署/数据库不自动阻断隔离实现，也不能据此操作生产。

## B01 基线、归属与消费者清单

- 输入：代码现状、当前 OpenAPI/schema、模型注册、Celery 配置与现有测试。
- 产物：记录基线 commit/工作树；为领域登记模型/表、写服务、HTTP/MCP/worker/脚本消费者、配置和测试；列出已有实现、缺失能力和待核验项。
- 规则：区分 HEAD、未提交试做、目标能力和实际部署，不导出环境密钥；未提交实现登记为待取舍，不能默认按其表/API 继续建设。先确认数据库迁移状态与真实消费者，再确定代码基线。
- 验收：AC01；每项迁移都能定位拥有者、消费者和验证方式。
- 回退：无运行时变化。

已完成静态地图、工作区分组和部分回归；数据库迁移状态、部署版本与真实消费者证据未齐，B01 不宣布整体完成。用户已授权实施，不依赖新表或 V2 取舍的存量事务切片可先行；不得据此清理数据库或迁移未知消费者。

## B02 整理模块、数据与事务边界

状态：B02.1–B02.5 已落地，范围与实际验证见实施记录；B02 整包未完成。词汇及考试/听力事实已逐个用例迁移，媒体 I/O 与字幕映射规则已从大文件分离，播放产物与发布共享校验、本地化使用既有派发 outbox。B02.6 的派发竞争、过期 worker 写回及字幕结构写入锁边界保留为待办，优先级服从上方 V2 主线。词汇请求级幂等、新词创建竞争与全量验证仍未完成，不因调整主线视作已解决。

- 输入：目标框架、B01 确认的代码基线、审查 REV01–REV05。
- 产物：先处理收款结算、通知派发与学习记录的事务拥有者；消除 task/service 对 HTTP 层的反向依赖，再提取判分/投影规则。目录搬迁后置，保留已提交接口、import 适配和 metadata 注册。
- 边界：不顺便改表名、GPU 任务名、调度算法、正式成绩语义或错误 envelope。跨域重用同一会话，不在内部偷偷 commit。
- 验收：AC02–AC05；旧业务回归、快照、重试/并发与队列补发验证。
- 回退：切回兼容层/旧实现，保留新增型数据；不靠降级删表回退。

## B03 教学运行时与记忆

- 输入：B01 取舍后的教学设计、CTX02–CTX06；工作区 teaching/run/content/exposure/outbox 仅作候选参考。
- 产物：先定版内容 revision/发布与单题状态契约，再按 [Agent 计划](agent-plan.md)交付独立聊天与任务关联、受控工具与 run，扩展阅读以外题型和视频/词汇教学；补记忆来源、查改删、过期、检索和账号生命周期，以及多语境/逐次复习日志与调度接口。算法决策遵守目标框架，不在此包另定路线。
- 边界：模型无答案提交/揭晓权限；派生掌握度与推断分开；记忆不保存完整私聊或跨用户知识。
- 验收：AC04–AC07、AC11、AC14–AC15；断连恢复、租约竞争、撤回来源、删除后缓存/旧任务负控及学习资产连续性。
- 回退：关闭新增题型/记忆/模型能力，保留原有确定性学习与可读历史。

## B04 网关治理与外部生态

- 输入：B02 业务接口、候选网关评估与正式权限契约；试做 LiteLLM/adapter/MCP 可作为对照，不强制沿用。
- 产物：补真实预算与生命周期证据；逐条迁移旧 AI/翻译出口；实现外部自行推理与受控托管，CLI/Skill 和公开授权；四宿主兼容矩阵。
- 边界：账本只在网关；不复制教学规则；商业准入、私测白名单与协议权限分别处理；不因接入成功放开写权限。
- 验收：AC08/AC09/AC11；两进程争最后预算、unknown usage、失败重试、late settle、凭据过期/撤销和同任务恢复。
- 回退：关闭外部写入/托管入口、撤销新凭据；模型出口按已验证开关回退，不能绕过预算直连供应商。

## B05 收费、运营与可观测性

- 输入：现有有效会员口径、金数据收款/对账、账号/管理员接口、网关账本引用。
- 产物：统一权益准入、日/月调用及成本预算；可信到账发放和补偿；运营读模型与审计；请求/任务/调用的关联追踪。
- 边界：不在本次文档冻结新价格；后台不得任意编辑不可变成绩、收款事实或网关账本；未知用量不当零。
- 验收：AC08/AC10/AC12；账号绑定、金额校验、重复通知、退款/到期、故障与清理意图告警。
- 回退：停止新销售/调用，保留已到账权益与历史事实；幂等补偿，不重复发放。

## B06 迁移演练与发布出口

- 输入：B01–B05 产物、已有 CI/安全/生产配置检查与隔离生产 smoke。
- 产物：新增迁移→隔离 PG 回填→数量/引用/成绩校验→影子读取对照→按开关切流；真实备份恢复、旧入口兼容和服务切回说明。
- 边界：任何破坏性删除后置独立版本；先校验消费者和备份恢复，再移除兼容层。生产发布遵循现有流程与当时授权。
- 验收：AC13 和全部上线硬门。GPU/网关拓扑与数据迁移分开验证，不用本地 mock 替代。
- 回退：关闭新入口/新消费者，切旧服务；保留新教学事实，核对积压与重复副作用。
