# 后端重构验收标准

结论只用“已执行通过 / 已执行失败 / 未执行”。下表是整体实施验收，不预先填通过。审查期的回归与问题复现见 [审查结论](review.md)；已落地切片的用例、AC 对应与检查结果见[实施记录](implementation.md)，局部通过不等于整项 AC 通过。

| 编号 | 必须满足的性质 | 验证场景/证据 | 实施包 |
| --- | --- | --- | --- |
| AC01 | 模块和事实有单一拥有者 | 模型/写服务/入口/任务/脚本消费者清单齐全；HEAD/试做/目标分开，V2 取舍及数据库状态明确 | B01 |
| AC02 | 装配与兼容不漂移 | 实际有效路由/schema 对照；旧 import、模型 metadata、错误 envelope、媒体 Range 和认证链回归 | B02 |
| AC03 | 身份、权限和披露一致 | 他人资源、伪造 actor/scope、封禁/改密/注销、过期/撤权；site/model/external 分别投影 | B02/B04 |
| AC04 | 可信内容与正式成绩不被改写 | 稳定题目键、冻结快照、来源撤回、重新导入；正式整卷与辅助 attempt 不串账 | B02/B03 |

| AC07 | 记忆可查改删且不越权 | 来源、确认、过期、用户纠错；跨用户检索、删除后缓存命中/旧任务复活均被阻止 | B03 |

| AC11 | 账号生命周期覆盖全部新数据 | 未揭晓答案不能经导出泄露；注销撤权、记忆/来源清理、网关意图与回执、在途调用结算 | B03/B04 |
| AC12 | 队列、故障和成本可运营 | API/worker request-id 与 run/call 关联；积压/租约/outbox/预算/收款/删除意图告警，日志不含凭据 | B05 |
| AC13 | 迁移和回退有实证 | 隔离 PG 迁移、回填与外键/数量/历史成绩校验、备份恢复、服务切回、旧任务消费和 HTTPS smoke | B06 |
| AC14 | V2 学习闭环完整且可恢复 | 可信材料初答→提示→复答→解析；任务对话与草稿恢复；聊天/组件专项见 [Agent 计划验收](agent-plan.md#8-验收与证据)；网页→外部辅助作答→网页恢复→撤权失效；逐材料/题型、两种推理模式及四宿主分别取得证据 | B03/B04 |

## 检查入口

命令在 `backend/` 执行，使用本机 `backend/.venv/Scripts/python.exe` 并设置 `PYTHONUTF8=1`；具体启动、数据库与安全要求以后端 `CLAUDE.md` 为准。

- 基础门：ruff、mypy baseline、依赖/安全门与受影响单测；后续真正搬迁完成时运行完整后端套件。
- 架构：`tests/test_architecture_invariants.py`，实际枚举有效路由，防止空集合假绿。
- 内容/考试/教学：考试快照、teaching、teaching_pg 等现有套件，加新材料类型与披露负控。
- 运行/账号：v2_runtime、v2_runtime_pg、v2_account_data；SSE 还需真实 HTTP 断连续读证据。
- 网关/MCP：现有 adapter、teaching_gateway 和 `scripts/check_v2_gateway.py` 为起点；stub 不替代真实预算/供应商或宿主。

PG 唯一约束、锁、并发和事务性质必须在隔离 PostgreSQL 验证；SQLite 和 mock 只能支持快速回归。任何 skipped、环境缺失或未执行必须单列，不把它们统计为通过。不得降低基线、改豁免或扩大超时掩盖真实问题。

## 上线硬门

1. AC01–AC15 对应最终 V2 范围全部取得真实证据；不满足前置则关闭对应能力，不宣布整体首发完成。目标对应见[目标框架 §0](architecture.md)，阶段性一题/单宿主通过不能代替 V2.0–V2.2 最终范围。
2. 提示/评分错误、未授权写入、未揭晓答案泄漏、重复副作用或预算失控均阻止放量。
3. 真实内容来源/许可、支付与对账、四宿主、模型成本、导出/注销和恢复回退都需实测；模板或设计文档不能代替。
4. 保留既有生产配置、安全和真实基线要求；部署仍走仓库既有流程，不因重构另建旁路。
5. 盈利需真实到账、退款、模型、短信、内容处理/存储带宽和运维成本数据；后端能收费不等于已经证明盈利。
