## 1. 产品现状盘点

### 1.1 定位与核心闭环

AI 英语词汇学习应用（品牌 SeeWord），面向中国英语学习者：

```
提交/浏览视频 → 观看（双语字幕 + 考试词高亮 + 点击查词）→ 加入词汇本
→ SM-2 复习 / 词汇 drill / 真题练习 / 句子跟读 → LearningEvent 回传
→ 学习档案（streak/掌握度/里程碑）+ 每日计划（规则引擎/AI）+ 推荐 feed
```

北极星指标（已定义于代码）：**周循环** = 一天内完成 4 类学习事件（观看 + 词汇 + 练习 + 复习）。

### 1.2 功能资产（按模块）

| 模块 | 状态 | 说明 |
|---|---|---|
| 视频管线（URL→转录→翻译→标注→ready） | ✅ 成熟 | WhisperX GPU 分离、断点续传、质量门（幻觉检测/翻译覆盖率）、标准版+Fork 去重 |
| 考试词汇体系 | ✅ 成熟 | ECDICT 本地标注，8 级体系（中考→GRE），按 target_exam 高亮 |
| 词汇学习 | ✅ 成熟 | 词汇本 + SM-2 + 自适应 drill + AI 释义/词注释（三级缓存：video→global→实时） |
| 学习计划与档案 | ✅ 成熟 | 规则引擎 + AI 生成（Pro）、streak/里程碑/掌握度趋势 |
| 真题练习/考试 | ⚠️ 可用但有 bug | 试卷库 + 三模式 + 服务端判分 + 错题本；「选项无法选择」两端复现（PLAN 任务 1A） |
| 跟读 Shadowing | ✅ 活跃 | 录音持久化 + 自评 + owner-only 回放（ADR-0013）；无 AI 评分（ADR-0002） |

| 会员/兑换码 | ✅ 成熟 | 4 态状态机、退款撤销、到期降级；¥9.9/月仅兑换码渠道 |
| 管理后台 | ✅ 完备 | 视频/用户/订单/兑换码/反馈/公告/平台设置/字幕编辑器全套 |
| 学习提醒 | ❌ 仅有设置入口 | preferences 有 reminder_* 字段、通知模型有 streak_warning/vocabulary_reminder/pro_expiring 枚举，但**无任何 beat 任务或触发代码**——设置是空转的 |

### 1.3 商业化与合规状态

- **收入渠道**：仅兑换码（ICP 合规要求 payments_enabled=false）。销售链路依赖微信小商店 + 人工发码，`/upgrade` 页为此做了三步指引降级态。
- **Pro 权益**：AI 查词、AI 学习总结/推荐、AI 计划生成（注意：`/plan/generate/ai` 路由层无 Pro 硬校验，仅服务层注释声明——免费用户实际可调用，属权益漏出）。
- **合规阻塞**：等待个体工商户营业执照 → 解锁在线支付与完整部署。

### 1.4 部署与运维风险（影响产品节奏）

- **HK VPS 单点依赖**：既是 `seeword.top` SSL 反代入口，又中转 GPU worker 回调；到期时间临近。封面加载异常很可能与之相关（PLAN 任务 3 已立项）。
- 媒体分发实际拓扑与仓库配置不符（仓库 nginx 代理到 backend 容器，`.agent/context.md` 描述为 HK VPS）——运维知识游离于仓库外。
- SMS send-code 502 根因已修复（requirements 补 SDK），待重装依赖后复测。

## 2. 产品阶段判断与核心主张

**阶段判断：功能完备、尚未正式上线。** 92 项需求全部完成、安全审查收尾，但被 ICP 执照、HK 迁移风险、关键交互 bug 挡在「可公开推广」之前。

**核心主张：未来 6 个月的主题不是加功能，而是「上线 → 跑通闭环 → 验证留存」。**

三个判断依据：

1. **功能面已经过剩于运营面**：学习闭环的每一环都有实现，但「让用户回来」的提醒体系是空的（1.2 表最后一行），内容供给依赖管理员手动 seed。先补齐运营基础设施，比任何新功能 ROI 都高。
2. **留存型产品的生死线是第 2-4 周回访**：SM-2 间隔重复的价值只有在用户坚持复习后才兑现；没有提醒、没有到期词汇的召回触点，streak 断掉即流失。
3. **变现验证必须等 ICP，但准备不必等**：兑换码渠道可以先行小规模验证付费意愿（种子用户 × 9.9 元/月），把支付接口当成 ICP 落地后的「开关」而非从零建设——代码已就绪（签名验证、订单对账、beat 任务齐全）。

## 4. 分阶段路线图

### Phase 0 — 上线阻塞解除（第 0-2 周）

目标：产品达到「可以安全邀请真实用户」的状态。全部为已立项任务，不新增。

| 事项 | 来源 | 验收信号 |
|---|---|---|
| rsync 部署通道 | PLAN 任务 4 | 本地改动可一条命令推上线 |
| 封面加载修复（去 HK 依赖设计） | PLAN 任务 3 | 首页/浏览页封面全部本地直出 |
| 试卷「选项无法选择」修复 + e2e | PLAN 任务 1A | 出卷→答题→判分→错题本全链路桌面/移动端通过 |
| SMS send-code 复测 | state.md 待办 | 真实短信发出，验证码登录闭环 |
| HK 到期迁移预案占位 | PLAN 任务 3 缺口 | `docs/operations/` 有预案文档 |

### Phase 1 — 上线准备与首批种子用户（第 2-6 周）

目标：邀请 50-100 名种子用户，拿到第一手留存数据。

| 事项 | 内容 | 为什么这个顺序 |
|---|---|---|
| **学习提醒体系落地** | 新增 beat 任务驱动 reminder_* 偏好：到期词汇提醒（复习日早间）、streak 保卫提醒（当日 21:00 未学习）、Pro 到期前 3 天提醒；走已有通知模型 + WebSocket 推送 | 留存型产品最便宜的召回手段；枚举、偏好设置、推送通道全部已存在，只欠调度与文案，是「存量资产盘活」而非新功能 |
| **漏斗报表** | admin stats 扩展激活/留存漏斗（基于 LearningEvent + behavior_events） | 没有基线就没有迭代依据；纯读已有数据 |
| **个人中心设计减法** | PLAN 任务 1B：按使用频率分层按键/选项，watch 页风格锚点统一 | 种子用户的第一印象页；方案需先出清单请用户拍板再动 |
| **内容供给 SOP** | 官方视频 seed 流程文档化 + 封面本地化纳入管线（承接任务 3 的回填脚本）；目标：上线时 ≥ 30 个覆盖主要考试级别的官方视频 | 推荐 feed 和内容发现的质量上限由供给决定 |
| **AI 计划 Pro 校验补齐** | `/plan/generate/ai` 路由层加 `require_pro_user` | 权益漏出修复，一行依赖注入 |

### Phase 2 — 增长闭环验证（第 1-3 个月）

目标：D30 留存与周循环数据达标（基线出来后定具体数字）；ICP 落地后立即切换在线支付。

| 事项 | 内容 | 依赖 |
|---|---|---|
| **推荐深度个性化（ADR-0011 P2）** | 基于 behavior_events 的个体化排序；与频道维度（下条）协同设计 | 行为数据积累 ≥ 4 周 |
| **视频频道（PLAN 任务 2）** | 先写 ADR：Channel 实体 vs channel_name 轻量聚合、与 category/tag 的关系定死；一期只做展示+分组，不做订阅 | ADR 通过 |
| **在线支付开关** | ICP 执照落地 → payments_enabled=true → 微信/支付宝直连（回调签名、订单对账、降级任务已就绪）；兑换码保留为礼品/活动渠道 | 营业执照 |
| **分享传播试验** | 学习成果卡片（streak/里程碑海报）→ 轻量分享；不做社交关系链 | 里程碑数据已有 |

### Phase 3 — 差异化与护城河（第 3-6 个月）

目标：形成「内容 × 个性化计划」的复购理由，验证 Pro 续费率。

方向候选（按投入从小到大，需数据支撑后再立项）：
1. **AI 计划深化**：从「生成今日清单」到「按掌握度趋势调整周目标」，mastery_snapshots 已在每日记录，数据基础具备；
2. **内容策展栏目化**：频道 + 专题（如「四级高频场景 20 讲」），把官方内容组织成课程感的路径；
3. **跟读体验增强**：在 ADR-0002 约束内（无 AI 评分）做原声对比波形、录音时间线等自助反馈，不再引入打分类 API。

## 6. 非目标（明确不做）

沿用既有 ADR 与 Cut Features，规划期内不重启：

- **AI 口语评分**（ADR-0002）——成本与准确率不成立；
- **社区 UGC**（ADR-0012）——不解决学习闭环核心问题；
- **用户面视频上传自动处理**（ADR-0004 精神）——GPU 成本与审核风险；
- **ICP 落地前的任何在线支付改造**。

## 7. 规划过程中发现的文档/代码缺口

1. **学习提醒空转**（见 1.2）：用户可设置 reminder_time，但无任何代码消费它。若决定不做提醒，应下线设置项以免误导；本规划建议做（Phase 1 首位）。
2. **`/plan/generate/ai` 无路由层 Pro 校验**：REQUIREMENTS.md §8 已指出，免费用户实际可调用 AI 计划生成。
3. **REQUIREMENTS.md §7 与代码冲突**：其称「练习/考试系统代码中不存在」，但 ExamRunner.tsx、PracticePanels 等前端组件存在，CHANGELOG 与 state.md 记录考试系统 08-04→08-13 活跃开发。该段描述失效，建议下次 knowledge-verify 时更正。
4. **媒体分发拓扑文档漂移**：`.agent/context.md` 与仓库 nginx 配置不符（PLAN 任务 3 已含更正动作）。
