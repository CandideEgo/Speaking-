## 1. 产品方向（已确认）

### 1.1 核心定位

看视频、学英语。核心功能三件套：**首页看视频、试卷练习、词汇本复习**。不做任务派发式学习计划，不做复杂 AI 权益分层。

### 1.2 访问模型：登录墙 + 会员墙

- **砍掉落地页**。未登录访问任何页面 → 直接跳 `/login`，不做营销介绍页。
- **注册即送 3 天 Pro 试用**，到期自动降 Free。
- **Free 每月可看 3 个视频，Pro 无限**。进入视频后 Free 与 Pro 功能完全一致，不做功能阉割。
- 视频管线的 AI 词注释是内容生产环节，保留，所有用户可见。

### 1.3 设计原则

沿用 Apple HIG + Material Design + Linear 框架，补充三条：

| 原则 | 含义 |
|------|------|
| **自主学习，不派任务** | 系统记录和反馈学习行为，但不规定"今天必须学什么/完成几项"。首页是仪表盘，不是任务清单 |
| **一次 session 一个闭环** | 每次打开能自然完成"看→查→练"中的至少两类，靠便利入口而非强制提醒 |
| **每扇关闭的门都留一扇窗** | 空状态/错误/额度用完，都给一个明确的低成本下一步 |

设计模式约束（继续遵守）：
- 破坏性操作 → 乐观删除 + Undo toast（5s）
- 加载 → 骨架屏，不用 FullPageSpinner
- 高频操作 → 最多 3 选项 + 键盘快捷键
- 新组件必须用语义 token；Tailwind v4 CSS-first

### 2.2 Free 视频解锁机制

**核心模型：解锁制，不是按月租借。**

- Free 用户每月有 **3 次解锁机会**
- 用户主动选择视频解锁，解锁后该视频**永久可看**（随时回看，不重复消耗）
- 每月 1 日刷新 3 次解锁机会（已解锁视频不受影响，持续可看）
- 当月未用完的次数不累计（简单，避免攒额度）
- 浏览首页/发现页/搜索不受限，所有视频信息（封面/标题/简介/难度）均可见

**数据模型**：新增 `user_video_unlocks` 表
```
user_id       (FK users)
video_id      (FK videos)
unlocked_at   (timestamptz, default now())
PRIMARY KEY (user_id, video_id)
```
- 已解锁视频：该表有记录 → 永久可看
- 本月剩余次数：`3 - COUNT(*) WHERE unlocked_at >= date_trunc('month', now())`
- Pro 用户不写入此表（Pro 期间看的视频不占用解锁额度；Pro 到期降 Free 后，Pro 期间看过的视频需重新解锁）

**解锁流程**：

```
Free 用户点击视频卡片
        │
        ▼
  进入 watch 页
        │
   ┌────┴────┐
   已解锁？   │
   是 → 直接播放（与 Pro 无差异）
   否 → 播放器区域显示「解锁面板」：
        ┌─────────────────────────────┐
        │  🔒 解锁这个视频           │
        │                             │
        │  《6 Tips on Being a...》   │
        │  TED · B2 · 15:18           │
        │                             │
        │  解锁后可随时观看，不重复消耗│
        │                             │
        │  本月剩余解锁次数：3        │
        │                             │
        │  [解锁并观看]              │
        │                             │
        │  开通 Pro，无限解锁所有视频 │
        └─────────────────────────────┘
        │
   点击「解锁并观看」
        │
        ▼
  INSERT INTO user_video_unlocks  →  播放器加载  →  开始播放
```

- 解锁按钮点击后直接解锁并播放（同视频不重复扣，无需二次确认）
- 本月 3 次用完后，解锁面板按钮替换为"本月解锁次数已用完" + [开通 Pro] 引导
- 已解锁视频在列表卡片上显示"✓ 已解锁"角标，点击直接进入播放

**额度检查位置**：
- 后端：`GET /videos/{id}` 返回 `access` 字段（`unlocked: bool` / `remaining_this_month: int` / `quota: 3`）；视频流/字幕接口校验：Pro 或已解锁才返回 200，否则 403
- 前端：watch 页读 `access`，未解锁渲染解锁面板；视频卡片根据 `unlocked` 显示角标

### 2.3 3 天 Pro 试用

- 注册成功后自动发放：`plan=pro`、`plan_expires_at=now+3days`、`plan_source='trial'`
- 试用期间功能与正式 Pro 完全一致
- 到期由已有 beat 任务 `downgrade-expired-pro` 自动降 Free，无需新代码
- 试用到期前 1 天发站内通知（复用通知模型）
- 试用不可叠加兑换码（兑换码在试用期间输入则顺延到试用结束后）
- 每个手机号仅一次试用（注册即发，无需条件判断）

### 2.4 解锁面板与升级引导

**未解锁视频（有剩余次数）**：播放器区域显示解锁面板（见 §2.2 流程图），主按钮"解锁并观看"，底部一行小字链接"开通 Pro，无限解锁"。

**次数用完（本月 0 次）**：解锁面板切换为升级态：
```
┌─────────────────────────────────────┐
│          🎬  开通 Pro               │
│                                     │
│   本月 3 次解锁已用完               │
│   开通 Pro，无限观看所有视频        │
│                                     │
│   ✓ 所有视频无限解锁、随时观看      │
│   ✓ 双语字幕 + AI 词注释            │
│   ✓ 真题练习 + 词汇复习             │
│   ✓ 跟读录音                        │
│                                     │
│   [输入兑换码激活]                  │
│                                     │
│   下月 1 日恢复 3 次解锁机会        │
└─────────────────────────────────────┘
```

**视频卡片状态**（Free 视角）：
- 已解锁：右上角 "✓" 角标，点击直接播放
- 未解锁 + 有剩余次数：右下角锁图标，点击进入解锁面板
- 未解锁 + 无剩余次数：锁图标 + 视频标题灰度 5%（仍可点击进入看升级引导）
- Pro 用户：无任何锁标

### 2.5 技术实现：Next.js Middleware

当前项目**无 middleware**，路由保护全靠客户端 `useRequireAuth`，未登录会先闪一下页面内容再跳登录。

**方案**：新增 `frontend/middleware.ts`：
- 从 cookie 读 `seeword_token`
- 无 token 且访问非白名单路由 → 302 到 `/login?next={path}`
- 有 token → 放行（会员/额度检查在后端 API + 前端做，middleware 不查 DB 避免性能问题）
- 登录后跳回 `next` 参数指定的原页面
- admin 路由单独检查 `seeword_admin_token`

**落地页清理**：
- 删除 `(landing)` 路由组（`(landing)/landing/page.tsx` + `layout.tsx`）
- 删除 `components/landing/LandingContent.tsx` 和 `AuthedRedirectGate.tsx`
- `MainLayoutInner.tsx` 删除未登录时渲染 `<LandingContent />` 的分支，改为：未登录时 middleware 已拦截，客户端只做 `isLoading` 骨架屏
- 根路由 `/` 直接是首页（`(main)/page.tsx`）

## 3. 学习计划减法

### 3.1 现状（首页截图实测）

首页当前有：
- "今日已完成 0/6" 进度环（0%）← **任务感来源，一进来就看到"没完成"**
- "2 天连续" streak
- "本周循环 0/7"
- "开始复习" 按钮
- 下方视频流

后端有完整的学习计划系统：`learning_plan_service`（规则引擎派任务）、`ai_plan_service`（AI 生成）、`LearningPlan/Item` 表、7 个 `/plan/*` 端点。

### 3.2 减法方案

| 保留（反馈/激励，无强制） | 砍掉（任务感/复杂） |
|---|---|
| streak 连续天数（纯展示，无断签惩罚文案） | "今日已完成 N/6" 进度环和目标 |
| 学习统计（已学视频数、词汇量、掌握度） | 规则引擎自动派发每日计划项 |
| 周循环 4 格（作为学习回顾，不施压） | AI 计划生成（`/plan/generate/ai` + ai_plan_service） |
| 词汇到期复习入口（便利按钮，不是任务） | daily_goal 每日目标设置 |
| 里程碑/成就 | 计划项完成/未完成状态 |

### 3.3 首页改造

**改造前**：进度环"今日已完成 0/6" + 开始复习 → 视频流
**改造后**：

```
下午好，学习者
8月27日星期四

┌──────────────────────────────────────────┐
│  🔥 2 天连续   📚 29 个词   🎬 5 个视频  │
│                          [开始复习 →]    │
└──────────────────────────────────────────┘

[推荐] [TED Talks] [Interviews] ...  [全部][A1][A2]...
[视频网格]
```

- 去掉进度环和"0/6"，改为一行紧凑统计（streak + 词汇数 + 视频数）
- "开始复习"按钮保留（有到期词汇时显示，无则不显示），点击进入词汇 drill
- 周循环 4 格移到 profile 学习进度页，不在首页施压
- 无计划时不显示任何"生成计划"入口
- 统计数据来源：`/plan/profile`（已有）+ `/vocabulary/stats`（已有），纯读

### 3.4 后端处理

- `/plan/generate/ai` 路由返回 410 Gone（或直接删除路由）
- `ai_plan_service` 代码保留 dormant（不删文件，避免大面积 import 改动），但不再被任何路由调用
- `learning_plan_service` 的规则引擎不再自动生成今日计划；`GET /plan/today` 返回空或 204
- `LearningPlan`/`LearningPlanItem` 表保留 dormant，不写迁移删除（不可逆操作暂缓）
- `LearningEvent` 继续发射（各服务已集成），`UserLearningProfile` 继续更新 streak/mastery——这些是统计数据源，不是任务系统
- `POST /plan/items/{id}/complete` 可保留 dormant 或返回 410
- onboarding 第 3 步"每日学习时长"设置保留（用于统计参考），但不再驱动计划生成

不做专门的教学视频（用户观看意愿低）。新用户 onboarding 完成后直接进首页，**第一次进入任意视频 watch 页时**触发高亮引导动画，用遮罩挖洞 + 阴影聚光灯指引核心操作。

**引导动画设计**：

- 实现：`components/common/CoachMark.tsx`，固定定位遮罩 `rgba(0,0,0,0.55)`，目标区域用 SVG mask 挖洞 + 洞缘 2px brand 色描边 + 呼吸动画（`box-shadow` 脉冲 2s 循环，CSS keyframes 实现，不引动画库）
- 气泡卡片贴在高亮区旁（自动判断上/下/左/右位置，移动端居中底部），带小三角箭头
- 4 步：

| 步骤 | 高亮目标 | 文案 | 触发条件 |
|------|---------|------|---------|
| 1 | 字幕区 | "点击任意英文字幕单词，查看释义" | 进入 watch 页即显示 |
| 2 | 词卡 | "点击「加入词汇本」，以后会提醒你复习" | 用户第一次点击字幕词、词卡出现后 |
| 3 | 练习区 | "看完可以做练习或跟读，帮助记忆" | 用户第一次加词成功后 |
| 4 | — | "准备好了，开始看视频吧！" | 点击"知道了"结束 |

- 底部有"跳过教程"文字链，点击立即结束并写 localStorage `seeword_coach_done=true`
- 步骤间用淡入淡出过渡（CSS opacity 200ms）
- 步骤 1-3 每步有"下一步"按钮，也可点击高亮区域直接进入下一步（步骤 1 点词、步骤 2 点加词自然推进）
- 不依赖特定视频，任意视频均可触发

**首次加词反馈**：词卡边缘金色高光 1.5s（CSS animation）+ 词卡底部"已加入词汇本"小字，不弹 modal。

**验收**：
- [x] 新用户首次进 watch 页自动触发，老用户（localStorage 标记）不触发
- [x] 4 步可跳过、可点"下一步"、可点击目标区自然推进

- [x] 移动端气泡位置不溢出屏幕
- [x] 引导期间高亮区可点击，其他区域被遮罩拦截
- [x] 首次加词有金色高光反馈

**工作量**：M（2-3 天，纯前端）

## 8. 风险与应对

| 风险 | 应对 |
|------|------|
| 登录墙 + 无落地页导致新用户不知产品是什么 | 登录页背景区放 1-2 张产品截图 + 一句话价值主张；种子阶段靠口碑/小商店详情页介绍 |
| Free 3 次解锁太严或太松 | 3 是初始值，额度是配置项；解锁制下已解锁视频永久可看，用户有积累感，种子期观察转化再调 |
| 试用被批量薅（同一人多手机号） | 种子阶段量小不做设备指纹；加同 IP 注册频率限制（已有 limiter） |
| Coach mark 干扰老用户 | 仅 onboarding 后首次进入 watch 触发，localStorage 可跳过 |
| 学习计划减法后首页太空 | 紧凑统计行 + 视频流填充；"开始复习"仅在有到期词时出现 |
| 波形对比被误解为 AI 评分 | 明确文案"不做评分"，不显示分数 |
| 单人带宽 | Phase 0 严格串行；Phase 1 的 D5 可拆为 streak展示/confetti/profile数据 三批交付 |
