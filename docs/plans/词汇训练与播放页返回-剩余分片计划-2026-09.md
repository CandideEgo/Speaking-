## 3. 各票详情

### S4｜干扰项生成重写（无 DEC）

**问题**（执行方案 §4-S4，行号为 09-25 快照，以符号为准）：`practice_service.py` 现取本批词译文去重后 `[:3]`，不随机、不看词性、不看相似度；候选不足 2 个时直接 `options=None`（题都出不来）。

**改动**

1. 新增独立干扰项选择函数，输入：目标词、用户词库、ECDICT、同一视频字幕词；输出 3 个干扰项。来源优先级（设计文档 §8.2）：
   1. 同视频 + 同等级 + 同词性的其它已加入词；
   2. 用户词库中同等级、同词性、编辑距离 2~4 的词；
   3. ECDICT 同等级同词性高频词（`services/ecdict.py`）。
2. 硬约束：**必须凑够 4 个**（1→2→3 逐级补齐）；排除与正确项释义互为同义/包含；释义去重；复用已有 `shuffle_options` 洗牌。
3. 修掉「候选不足即 `options=None`」的兜底洞。

**注意**：题型轮换（按出现次序选英→中/中→英/听音选词，现在是按 mastery 随机）**归 S5**，不在本票——但改动落在同一文件，S5 须排在 S4 之后。

**验收**（执行方案 §4-S4）：每题恰好 4 选项含 1 正确项；选项与正确项同词性（缺失时至少同长度档）；用户词库只有 2 词仍能出 4 项；无同义/包含选项；选项顺序可复现地被洗牌。

**测试**：`backend/tests/test_vocabulary_quiz.py` 现仅 7 行 docstring，在此补齐函数级测试（按 §8.2 三级来源 + 兜底 + 去重分 case）。

### S6｜复习间隔新算法 + 同日优先级（先出 DEC）

**DEC**：SM-2 → 错误次数分档是算法替换（执行方案 §1 第 ② 处）。开工前出 DEC。

**改动**（执行方案 §4-S6 + 设计文档 §5.4）

- `services/sr_service.py`（原 `:47-64`）：`1 / 6 / interval × ease_factor` 改为按下表直接算 `interval_days` 与 `next_review_at`；**保留 SM-2 所有列**，`ease_factor` 不再参与计算（留作兼容/显示）。

| 情况 | 下次复习 |
|---|---|
| 本轮内答错过 | 次日（1 天） |
| 本轮内一次没错 | 3 天后 |
| 复习时答错 | 回到次日，`wrong_count += 1` |
| 全对且 `wrong_count = 0` | 3 → 7 → 16 → 35 天 |
| 全对但 `wrong_count ≥ 1` | 2 → 5 → 12 → 25 天 |
| `wrong_count ≥ 3` | 间隔上限 7 天 |

- 复习队列排序（`vocabulary_service.py`，原 `:129-140`）改为：昨天错过的优先 → `wrong_count` 降序 → 到期时间升序。
- `api/v1/vocabulary.py` 的 review 端点补写 `wrong_count` / `last_wrong_at`。

**验收**：表驱动测试覆盖上表六情形 + 同日出队顺序（构造「昨天错 3 次 / 昨天错 1 次 / 昨天没错」断言顺序）。
