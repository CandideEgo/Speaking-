# 首页新版设计稿 · 同行评审

**对象**：`design-original.png`（1158×1359 新稿）对照 `current-original.png`（现状 125%，红框=待替换区）
**依据**：`beta-prototype-alignment-2026-10.md` §1 / §12 / §14
**口径**：字号按 1158px 稿估测（±1–2px）；对比度用实测像素算 WCAG 比值；只评审不改码。

## 一句话诊断

**优点**：首页第一次有了「今天」的骨架——三张动作卡把「继续 / 复习 / 练」搬进开场，01、02 两个区块让页面从「一柜子视频」变成「今天这三件事」，主动连接的方向成立。
**风险**：三件事被做成三等分，谁都不是主角；首屏最大权重给了 36px 品牌句，第一动作只剩 15px 一格，主 CTA 在 y=882–927（900 高视口只露 18px，800 高看不见）。
**盲点**：新稿靠编辑标题、人工挑词、场景标签撑密度，仓库没有这些字段（`homeLearning.ts` 是按标题写死的映射，匹配不到退回通用 label），上线先露馅的是硬编码文案与空块。

## P0 · 首屏与核心转化

**P0-1 三卡改「一主两次」**
- 现状：三卡等高 70px、三等分；标题 15px、状态行 14px（`0:17 / 9:24 · 接着听 →`）。
- 问题：一天只有一个下一步；并列逼用户先选择，唯一零成本的「继续」没有主角。
- 改成：主卡 2/3 宽、96px 高，缩略图 + 16px 标题 + 4px 进度条 + 实心 `继续观看`；另两张压成 40px 次级入口。
- 效果：首屏只剩一个「点这里」。成本 **低**。

**P0-2 h1 让位给用户状态**
- 现状：`每天一点好奇…` + 36px `打开英语，也打开世界。`；h1 与 hero 标题同为 34–36px 级。
- 问题：最大的字在讲品牌不在讲「你」，两个最大声的字互抢等于没有层级。
- 改成：h1 改 `今天继续 Bob 的动作英语`；品牌句降 13px 眉题或仅首访出现；删「有意思，也有收获」。
- 效果：一眼看到自己的进度。成本 **低–中**（新增 h1 需同步 `container-align` 锚点）。

**P0-3 主 CTA 进首屏、换成学习动作**
- 现状：实心 `#c4411c` 188×46，文案「看看这期学什么」，y=882–927；旁注「点词释义 · 场景例句 · 收进词本」。
- 问题：位置让它多数时候看不见；「看看」是浏览动作，点完仍不知从哪开始。
- 改成：移到封面下、与标题同屏（y≤760），文案 `从第 1 句开始 · 9:24`（有进度则 `接着学 0:17`）；旁注删。
- 效果：首屏即可开播。成本 **低**。

**P0-4 点词条补回学习闭环**
- 现状：一行三词（`spot` 实线、`fake`、`tell the difference` 虚线），下只有释义 + 描边 `收词`，无音标无发音。
- 问题：逐词点读 + 跟读是差异点，现稿做成展示，点词只能看中文，听不到也跟不了。
- 改成：拆开多词短语；点词后给 `spot /spɒt/ v. 发现；识别出` + `听原声` / `跟读` / `收进词库`（点后变 `已收词 ✓`）。
- 效果：首屏完成一次「点—听—收」。成本 **中**（复用 word/clip 接口）。

**P0-5 空态矩阵**
- 现状：三卡与 hero 都按「有历史、有到期词、有精选」画，新用户首访无变体。
- 问题：公测第一批全是新用户，首屏是唯一一次第一印象。
- 改成：无续播→主卡 `今天从这段开始`；0 到期词→`词库 12 词 · 今天没有到期`；未登录→一行 `登录后同步进度`；`show_on_homepage` 全空→hero 回落推荐流第一条；02 无内容→整块不渲染。
- 效果：任何账号都有完整首屏。成本 **中**。

## P1 · 体验与状态（公测前改）

**P1-1 侧栏 / 顶栏补齐 IA，否则手机断链**
- 现状：设计侧栏 6 项（缺我的 / 通知 / 会员），底部是 slogan，顶栏只有搜索；现状 9 项 + 头像菜单 + 折叠，顶栏有 ⌘K、铃铛、账号。
- 问题：`MAIN_NAV` 是手机底栏唯一来源，删「我的」底栏 5 变 4，`/profile`、会员、退出登录在手机零入口。
- 改成：恢复 5+4 两组 + AccountMenu + 折叠按钮；词汇补 `239` 徽标；顶栏补铃铛与 ⌘K；slogan 删。
- 效果：桌面手机都不断链。成本 **低**（不删即可）。

**P1-2 元数据与命名统一**
- 现状：hero 只有 `TED · Hany Farid` + `约 12 分钟`（现状是 `A2 · 9:24`）；三卡是 `0:17 / 9:24`；来源写法三种（`TED · Hany Farid`、`关系与沟通 TED`、`约朋友 · 临时有事`）；同一槽位三个名字（每日精选 / 本周精听 / 今天值得听懂）。
- 问题：自学者靠多难、多久、学没学决定现在学不学，缺级别只能点进去试；模糊时长与播放器打架。
- 改成：封面下固定 `A2 · 9:24 · 18 句 · 已学 0:17`（字段全已有）；小卡补级别与时长；`每日精选` 加日期；全站定一个名字，`featured` 缓存按日 key。
- 效果：不点进去就能判断。成本 **低**。

**P1-3 写操作要有状态**
- 现状：`收词`、02 卡书签、卡右上 `↗` 均无悬停 / 已选 / loading / 失败态。
- 问题：静默失败最伤信任；收词是写操作，没有回声用户不知道值不值得继续。
- 改成：四态（悬停 `#f1f2ed`、已选实心、loading 转圈 + 禁用）；收词成功 toast `已收进词库 · 去复习`；书签变实心并给「去我的收藏」。
- 效果：每个动作有回应。成本 **中**。

**P1-4 02 区先解决数据来源**
- 现状：三卡需要场景标签 + 英文句 + 中文 + 说明 + 收藏态 + 可听音频，现有只有字幕句与时间戳。
- 问题：这是最像产品的一块，也最可能上线即空；没音频的句子卡无法学习。
- 改成：v1 手工配 3 条（句、中文、场景、音频区间），无音频不入卡；主操作由 `↗` 改 `听这句`，整卡点击展开释义。
- 效果：新板块可上线可运营。成本 **高**（配置表 + 运营，可降级为热门字幕取句）。

**P1-5 下滑流与移动端折叠（两处空白）**
- 现状：只画到 `找点你感兴趣的` + 5 个 chips（现有 8 个主题 + 难度 + 排序 + 计数），没有视频卡；全稿单一桌面布局。
- 问题：首屏之后下滑流承担全部流量，卡片缺元数据等于盲点；折叠不定义会做出三种首页。
- 改成：补卡（16:9 + 来源 · 级别 · 时长 + 标题 + 已学进度）；chips 补齐并留 `筛选`；<768 侧栏换底栏 5 项、h1 24px、主卡全宽 64px、hero 16:9、右列挪到下方两行、02 单列露 1.5 张。
- 效果：下滑区与手机都能落地。成本 **中**。

**P1-6 可访问性**
- 现状：副文灰实测最低 4.12:1（14px 那档）；分组靠 `#e7e8e2` 描边（1.18:1）；`收词` 73×34、chips 高 34、书签约 20px；无可见焦点态。
- 问题：小字低亮度屏读不清；34px 低于 44px 触控下限；无 `focus-visible` 键盘没有位置感。
- 改成：次要文字压到 ≥4.5:1（`#616860`）；卡片改白底 + `#dcdcd4` 1px + 微阴影；热区补 44×44；统一 `focus-visible: 2px #c4411c offset 2`；封面压 24px 底部渐变。
- 效果：达 AA，键盘可走完首屏。成本 **低**。

**P1-7 文案：删说明，换成收益**
- 现状：六处说明 / 营销——`每天一点好奇…`、`有意思，也有收获`、`一个新视角，几个好表达`、`一句话，对应一个真实场景`、`继续往下逛…`、`点词释义 · 场景例句 · 收进词本`。
- 问题：没一个在回答「点下去会发生什么」，违反 §1.4「文字过多、可视化优先」。
- 改成：品牌句只留一处；栏副题换收益数字（`3 分钟 · 3 句能马上用的英语`）；按钮旁说明删；02 卡第三行与中文翻译重复，删。
- 效果：文字量减三分之一。成本 **低**。

## P2 · 打磨

**P2-1 区块标签收敛**
- 现状：`01 / 02` 编号 + `今天，值得听懂` + `一个新视角，几个好表达`；02 之后还有未编号的 `找点你感兴趣的`。
- 问题：编号暗示有序课程，体系自己就断了；四层标签堆在一个 hero 看不出主次。
- 改成：去掉编号与 `一个新视角…`，只留 `每日精选` 前缀；「本期主打」「编辑精选」二选一。
- 效果：结构一眼可读。成本 **低**。

**P2-2 两个 token 收尾**
- 现状：绿色 `#516650 / #edf1e8` 作强调色未登记；时长 / 进度非等宽；箭头混用（`↗` 去详情、`→` 继续）。
- 问题：未 token 化会各写各的绿；比例字体让 `0:17 / 9:24` 跳动；两种箭头让「点哪里」不明确。
- 改成：绿色登记为「例句」token；数字加 `tabular-nums`；`↗` 只留给外部 / 新页。
- 效果：实现一致，进度不抖。成本 **低**。

## 如果只改 3 处

1. **P0-1 三卡改主次**——首屏只能有一个主角，这是主动连接成不成立的分水岭。
2. **P0-2 + P0-3 品牌句降级、主 CTA 进首屏换成学习动作**——同一次点击的两半，决定第一屏有没有能立刻点的学习动作。
3. **P1-1 补回我的 / 通知 / 会员 / 账号**——不是视觉问题而是可达性：不改，手机端连 `/profile` 都进不去，公测收不了尾。

为什么不选点词闭环（P0-4）：它属于「不回退就能保住」的能力，成本最低，写进实现清单即可，不必占前三。前三条的共同点是——不动视觉语言，就能把主动连接从概念变成首屏的一次真实点击。
