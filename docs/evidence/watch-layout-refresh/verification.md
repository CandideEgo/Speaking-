# 播放页布局与缩放验收 · 2026-10-26

已实现桌面拖动分栏、放大与恢复、容器不足时上下排布，以及手机标准／紧凑画面和导航上方的常驻播放栏。画框尺寸独立于字幕、学习操作和笔记，切换布局保持同一媒体节点和播放进度。

## 验证结果

| 检查 | 结果 |

移动端跳过的是依赖本地视频长句的用例：专用种子视频没有符合长度要求的句子。固定长句、大字号、展开阅读与短视口词卡由上述隔离测试覆盖。句导航回归使用 16 条固定字幕和可播放的本地媒体，保留连续前进、后退及真实媒体时长断言。

检查通过仓库内工具的 Node 入口执行，覆盖 `npm run check` 的五道门。浏览器报告在本地 `frontend/test-results/watch-layout-complete.json` 与 `watch-mobile-verified.json`，它们是忽略的运行产物。

## 覆盖场景

- 桌面 1280×720、1366×768、1920×1080、2560×1440、2560×1080；分栏拖动与键盘边界、重置、放大恢复、布局偏好恢复。
- 手机宽度 320–430px、1024px 平板和 844×390 横屏；滚动贴顶到页面末尾、标准／紧凑切换、两层底栏、词卡避让和焦点恢复。
- 播放中跨断点保留媒体和进度；长标题、长句、笔记、大字幕、空字幕、媒体失败、原句重听、点词与收藏。
- 修复浏览器自动滚动将词放到视频下面、字幕高度变化触发滚动锚定、以及视频在页面末尾被包含块推出视野的问题。

125%、150%、200% 缩放采用等效 CSS 视口验证；真实浏览器原生缩放和手机真机验收未执行。手机浏览器项目为 Playwright 的 Android Chrome 与 iPhone WebKit 模拟环境。
