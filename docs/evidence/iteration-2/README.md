## 文案与代码的对照

- 购买页顶部写明「内测期：全站免费，购买是支持开发」，并区分「现在免费用什么」与「付款买到什么（会员身份 + 到期日）」；
  权益卡标题为「现在所有人都能免费用 / 内测期间对登录用户全部开放」，不再把已免费的能力写成会员专属。
- 购买卡列出三档的金额与天数（月卡 ¥19.90/30 天、季卡 ¥49.90/90 天、年卡 ¥199.90/365 天），并说明「本次金额与天数即时计入会员到期日」；
  FAQ 补齐「现在免费为什么还能购买」「何时开通」「会自动续费吗（从现在或本次已购到期日往后顺延）」「到期之后」。
- 与后端一致：内测期 `unlock_service.get_video_access_info` 对任何登录用户返回 `unlocked=True`；续期按 `max(当前到期, 现在) + 天数`。

## 视口与分支

- 1440×900（桌面）：侧边导航与账号菜单正常，页面内容完整。
- 390×844（移动模拟，iPhone UA）：`document.documentElement.scrollWidth === innerWidth === 390`，**无横向溢出**；
  购买区显示「请在微信里打开后再支付」+ 复制支付链接（移动浏览器分支）。
- 微信 UA（`MicroMessenger`）：购买区显示「去支付」主按钮，且不再显示「请在微信里打开后再支付」（微信内分支）。
