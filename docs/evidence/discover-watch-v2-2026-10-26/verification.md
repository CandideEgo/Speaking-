# 发现与观看体验 · 第二版

本轮重新组织内容与操作层级。只调整用户端及复用展示组件，保留工作区内管理端的并行修改。

## 设计变化

| 区域 | 第二版处理 | 使用上的目的 |
| --- | --- | --- |
| 首页首屏 | 无续看记录时省略空条；真实续看保留进度与恢复入口 | 将首屏空间留给可观看的内容 |
| 今日精选 | 封面保持 16:9；按组件宽度切换横排与上下排列；标题使用更收敛的字号 | 让封面完整，长标题也有稳定层级 |
| 学习右栏 | 合并为一个浅色面板，保留到期词、订阅频道、周统计与真实进度 | 减少重复边框和多个主按钮争抢注意力 |
| 筛选 | 轻量分类标签、独立设置行、自定义下拉箭头、一键清除条件 | 保持选项完整，同时明确当前选择；清除条件保留用户排序 |
| 视频列表 | 按内容宽度分列，标题优先，来源与图标数据在后 | 提高卡片可读性，避免过窄的密集卡片 |
| 普通观看 | 当前句使用浅色字幕带；重听为蓝色主操作，切句为次级操作；手机画面工具用图标 | 让高频操作更容易定位 |
| 沉浸观看 | 临时使用深色观影配色；手机将画面和字幕作为一组居中；桌面提供常驻角落退出入口 | 减少视觉干扰，让字幕紧跟画面，退出不受视频宽高比影响 |
