Next 16 dev tools「N Issue」徽标调查记录（截图 08 左下角）

背景
- 第一版 08-首页-恢复后-A-1440.png 左下角出现 Next dev tools 红色徽标「1 Issue」。
- 该徽标来自 dev overlay：DOM 在 `nextjs-portal` 的 shadow root 内，
  `#devtools-indicator [data-next-badge]`（Next 16 内置 dev tools indicator，
  与仓库刻意关掉的 `devIndicators` logo 不是同一个东西）。它会自行折叠/隐藏，
  `[data-next-badge-root]` 在无活跃 issue 时 `display: none`。

调查方法
- Playwright chromium，真实 dev 后端 + dev 代理，已登录访问 `/`（恢复后 A 状态与
  新编排 B 状态都试过）。
- 监听 `console`（error/warning）、`pageerror`、`response >= 400`、`requestfailed`。
- 复现路径 A：fresh context → `/`。
- 复现路径 B：管理员 `/admin/home-editorial` → 切换普通用户 token → `/`（截图 08 同一路径）。
- 每条路径重复 3~6 次；额外尝试在徽标可见瞬间通过 CDP 鼠标点开 issues overlay。

原始观测（逐字）
1) false 页面加载时偶发（2/9 次，racy）：
   [requestfailed] GET http://localhost:3000/api/v1/browse/featured?limit=6 :: net::ERR_ABORTED
   [requestfailed] GET http://localhost:3000/api/v1/discovery/learning-metadata?ids=28091082-12e9-47dd-ab0c-8533e3bc27a8%2Cfd0bed6c-109d-444a-8075-663beb783f3d%2C8f1f8f1a-8f7e-4b18-b740-ff684db20d5a%2C63288cd3-2789-47d7-ba66-a83c982f33a9 :: net::ERR_ABORTED
2) 其余运行（7/9 次）：
   console.error: 0；pageerror: 0；http >= 400: 0；requestfailed: 0
3) 所有探针都没有捕获到 React hydration 错误、未捕获异常或 4xx/5xx；
   `nextjs-portal` 内也没有出现 error dialog（只有 dev tools 的隐藏 indicator 骨架）。

判断
- 「N Issue」是 Next 16 dev overlay 的计数徽标，不是页面运行时错误；
  没有 hydration 报错、没有未捕获异常、没有失败的业务请求。
- 唯一相关的异常是 dev-only 的 `net::ERR_ABORTED`：React StrictMode 在 dev 下
  双执行 effect，首页 `page.tsx` 的首次 `fetchHomeEditorial` 被 cleanup abort；
  该 abort 被 `.catch(...)` 当成失败，短暂渲染旧 `FeaturedListening`，
  随后第二次请求成功又把旧组件卸载，导致 `featured` / `learning-metadata`
  在途请求被 abort。这是 dev-only 行为（生产构建不会双执行 effect）。
  是否正是该 abort 被 dev overlay 计成 Issue：徽标出现是 racy 的，未能稳定复现并
  读出 overlay 明细，故只作为「最可能来源」记录，不当作已证实结论。
- 与本功能的关系：仅经由新首页加载路径（`frontend/src/app/(main)/page.tsx` 的
  AbortError 处理）间接相关；不影响数据、契约、发布/回滚正确性，也不进入生产构建。
- 若后续想消掉：在 `fetchHomeEditorial(...).catch` 里先判断 `controller.signal.aborted`
  再决定是否 `setEditorial({status:"fallback"})`（属实现代码，验证者未修改）。

验证者处置
- 交付截图统一在截图前收起该 dev-only 徽标（`dismissNextDevIssueBadge`），
  截图 08 已无徽标。

  失败请求只允许 ERR_ABORTED」写成断言，并把原始事件写入
  `12-homepage-console.log`。
