# SeeWord 视觉、布局与交互评审

评审日期：2026-10-21。对象：本地 `http://localhost:3000` 当前工作区的用户端页面。

## 结论

基础视觉语言已经统一：白色背景、橙色行动色、细边框、统一导航，以及视频旁的当前句与文稿。影响体验最大的，是手机端空间预算与跨页面任务衔接。应优先修复查词正文不可见，再处理首屏控制区、片段任务和复习信息口径，最后调整视觉细节。

本次确认 1 项 P1、7 项 P2，另列 1 项 P3 设计建议。P1 表示核心任务在复现场景下受阻；P2 表示明显增加理解或操作成本；P3 表示需要通过设计验证的优化建议。优先级是本次评审判断。

## 范围与验证边界

- 实际访问：首页、观看页、手机查词卡、更多设置、词汇今日页、训练准备页。
- 实际操作：首页片段跳转、播放与暂停、点词与关闭、打开设置并按 Escape、进入复习准备页。
- 视口：桌面 1440×900、1280×720；手机模拟 390×844、375×667。截图使用明确的 CSS 视口尺寸，已核对 `innerWidth/innerHeight`。
- 数据来自本地已有登录会话和本地数据库；未使用模拟 API 替代页面结果。观看操作可能正常更新本地观看进度；未点击加入词库、提交复习答案或修改学习设置。
- 已通过运行时 DOM 测量、截图和对应源码交叉核对。未执行自动化回归套件、真实手机测试、跨浏览器测试、暗色模式评审、完整一轮复习，以及片段终点的连续播放计时验收。
- 未修改业务代码。工作区原有大量未提交改动，本报告针对读取时的当前实现，不归因于某次提交。

## F1 · P1 · 交互 / 布局：手机词卡正文被挤为 0px

**复现：** 390×844，观看页滚动到顶部，定位 Bob 动作动词视频 8:09 的句子，点击 `slip`。词卡出现，但用户看不到词义，发音和加入词库按钮也有裁切。

**测量：** 页面滚动量为 0；词卡顶边约 543.2px，底边约 783.2px，总高 240px。把手 16px、词头与等级区 138px、重听区约 50.4px、底部操作约 68.8px、回看原句 36px，固定内容已超过卡片总高。释义滚动区 `clientHeight = 0`，其内容高度为 1049px。这个状态无法通过在释义区内部滚动来阅读。

**原因位置：** [WordCardSheet.tsx:70](C:/Users/Administrator/Speaking/frontend/src/components/watch/WordCardSheet.tsx:70) 根据剩余高度限制整卡；[WordTooltipInline.tsx:222](C:/Users/Administrator/Speaking/frontend/src/components/subtitle/WordTooltipInline.tsx:222) 将正文设为可压缩区域，其前后的词头与多组操作消耗全部空间。页面滚到别处后，卡片可变高，不能据此判断顶部场景正常。

**建议：** 先保证词义可读的空间预算；压缩考试标签、合并重复操作，空间不足时允许整张卡片内部滚动或切换为更高的阅读面板。不要只提高一个最小高度常量。

**验收：** 上述场景直接看到至少一条完整释义；释义区始终有正高度；发音、保存、关闭均可触达。覆盖多标签词、错误提示、加载态、长译文和两种手机高度。

## F2 · P2 · 布局：短屏观看页的显式播放与重听落在首屏外

**复现：** 375×667，页面在顶部，使用同一个较长英文标题。标题占三行，前面还有全站顶栏、返回行和元信息。用户首屏看得到视频和字幕，但看不到显式播放、上一句、下一句、重听按钮。

**测量：** 播放控制区从约 y=603.25 延伸到 704.85；底部导航从 y=606.4 开始。控制区只有最上面的进度线进入可见内容区，其余需要滚动后使用。画面本身可能支持点击播放，但没有替代显式按钮的可见提示。

**位置：** [watch/page.tsx:827](C:/Users/Administrator/Speaking/frontend/src/app/(main)/watch/[id]/page.tsx:827) 的手机 PageHeader；[watch/page.tsx:1066](C:/Users/Administrator/Speaking/frontend/src/app/(main)/watch/[id]/page.tsx:1066) 的自然流播放控制区。

**建议：** 手机页头默认压缩长标题，允许展开查看；按可用高度分配播放器、当前句和控制区空间。至少让播放与重听在首屏可见。

**验收：** 375×667、长标题、双语长句条件下，无需先滚动即可找到并操作播放与重听，且按钮不与全站导航重叠。

## F3 · P2 · 交互：49 秒学习任务进入后丢失任务上下文

**观察：** 首页提供中文任务“绊倒、打滑、踮脚：3 个词怎么用”和“听懂这段 · 49 秒”。点击后能够定位到原片对应时间，但观看页呈现的是完整英文视频标题、9:24 总时长及 218 句文稿，没有显示这次片段任务、片段范围或完成反馈。

**实现核对：** [homeTask.ts:130](C:/Users/Administrator/Speaking/frontend/src/lib/homeTask.ts:130) 构建链接时只传起点字幕、开始时间和 autoplay，没有传片段终点。片段终点连续播放是否暂停未做计时验收；本项确认的是页面上下文缺失与入口未传递片段终点。

**影响：** 用户无法判断“这 49 秒到哪里结束”“现在是否仍在今日任务里”“下一步做什么”。完整视频与短任务的区分只存在于首页。

**建议：** 将任务标题、稳定片段标识与起止范围带入观看流程，显示片段进度，在结束时提供重听片段、继续完整视频或回首页的明确选择。如果产品只提供定位播放，入口文案应明确这一点。

**验收：** 进入后可立即确认任务、范围和剩余时长；到达终点有明确反馈；“看完整视频”仍可独立进入完整观看流程。

## F5 · P2 · 交互：没有原句定位信息时，训练页仍标“去原句”

**观察：** 训练准备页 `citing` 等词旁边显示“去原句 →”，实际链接只有 `/watch/{id}?from=drill`，没有字幕 ID、词或时间定位。它能打开视频，却不能兑现“去原句”的承诺。

**位置：** [drill/page.tsx:563](C:/Users/Administrator/Speaking/frontend/src/app/(main)/vocabulary/drill/page.tsx:563) 在缺少 `subtitle_id` 时退回视频链接，但 [同文件:573](C:/Users/Administrator/Speaking/frontend/src/app/(main)/vocabulary/drill/page.tsx:573) 的文案不变。词汇今日页已经按数据区分“原句”和“来源视频”，可保持一致。

**建议：** 有原句定位才显示“去原句”；缺少定位时显示“去来源视频”。不要自动猜测该词在视频中第一次出现的位置。

**验收：** 以有、无字幕 ID 的词各验证一次；文案与实际落点一致。

## F6 · P2 · 视觉：主按钮白字对比度不足

**测量：** 首页“继续学习”和“听懂这段”均为 15px、字重 600、白字 `#ffffff`、背景 `#ff5a1f`。按实际前景与背景色计算，对比度为 **3.1184:1**。

这类字号不属于大号文字。普通文字最低对比度要求为 4.5:1，见 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。此处评估的是已测按钮，不代表已完成全站无障碍审计。

**位置：** [globals.css:28](C:/Users/Administrator/Speaking/frontend/src/app/globals.css:28)、[globals.css:83](C:/Users/Administrator/Speaking/frontend/src/app/globals.css:83)、[Button.tsx:27](C:/Users/Administrator/Speaking/frontend/src/components/ui/Button.tsx:27)。

**建议：** 为按钮填充选择满足白字可读性的品牌色阶；分别核验默认、悬停及两种主题，不能靠放宽检查规避。

**验收：** 普通字号的有效按钮文字对比度至少 4.5:1，同时保留可辨认的悬停与焦点状态。

## F7 · P2 · 视觉 / 信息表达：词典原始字段直接进入学习界面

**观察：** 词汇列表和训练准备页显示 `v:100`、`v:15/n:85`，释义混有 `[建]`、`[计]` 等缩写和很长的多义项串。用户需要自行区分音标、词性、频率字段和当前语境释义；例如 `objected` 的展示先从名词“物体”开始，增加理解负担。

**位置：** [VocabularyToday.tsx:227](C:/Users/Administrator/Speaking/frontend/src/components/vocabulary/VocabularyToday.tsx:227)、[drill/page.tsx:548](C:/Users/Administrator/Speaking/frontend/src/app/(main)/vocabulary/drill/page.tsx:548) 直接展示 `part_of_speech`。本项不判断数据库所有释义的准确性。

**建议：** 展示层归一化词性，默认给最相关的简短释义，完整词典内容按需展开；原词、原形与词形变化应清楚区分。考试标签采用少量、有明确用途的强调色，避免与释义争夺注意力。

**验收：** 上述两个示例词不再直接显示词性比例串，用户不必理解词典字段格式即可辨认词性与释义。

## F9 · P3 · 视觉 / 布局建议：首页的图像和行动层级可以更克制

**观察：** 当前数据下，继续学习与今日精选指向同一个视频，却重复显示同一张较大封面。390×844 首屏被继续学习和第二张封面占据，今日任务按钮在首屏之外。1440×900 下，两处行动都使用实心橙色。低于 xl 断点时，复习与找视频入口还会排在精选及场景区之后。

**建议：** 手机继续学习改为紧凑横排；同视频时减少重复封面。有续学记录时，精选用较弱行动样式；将小轮复习入口放在更靠前的位置。现有字体和导航体系可保留，不需要为追求“高级感”整体换肤。
