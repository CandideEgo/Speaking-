# 词汇页与真题页的呈现方式调研

日期：2026-10-22。对象：SeeWord 用户端词汇、真题列表、作答和结果页。

## 结论

建议词汇采用「本轮任务 → 带原句的词条 → 词库与词单」，真题采用「选卷目录 → 阅读工作区 → 错题回顾」。两者共享简洁排版和来源信息，但各自围绕复习、作答组织内容。

最值得先做的三件事：

1. 词汇首屏用真实队列说明本轮内容，给一个清楚的开始按钮；累计到期量降为辅助信息。
2. 真题桌面作答让文章与当前题组并排；手机让文章、题目可以来回切换，并保留位置和选择。
3. 删除重复说明，把功能范围放到正确位置；未开放的听力、写作、翻译收进选卷页的一句说明，作答区只展示实际可做的题型。

这些是基于产品资料与代码的设计判断，尚未经过用户测试，不能据此宣称能提高学习效果或转化率。本轮不修改业务代码。

## 2. 当前实现：哪些已经有，哪些值得调整

### 词汇

当前默认「复习」，另有「词库」入口；`VocabularyToday` 已展示词、音标、可读词性、词典释义、原句及来源链接，首批预览六词。全部单词视图支持服务端搜索、掌握状态和到期筛选；视频集合另有详情与过筛路径。

因此，「增加原句」「区分词库与训练」已有实现基础，下一步应改善权重与状态，而非重复建设。

- 页头标题突出累计到期数量，开始按钮却对应按配额生成的本轮。需要更清楚地分开累计队列、本轮数量和今日完成量。
- `VocabularyToday` 有复习词时优先只预览复习词，页内文案却同时描述本轮复习和新词。建议分成「复习词」「新词」两个短分组，避免用户以为预览就是完整队列。
- 无到期词时按钮由每日新词偏好生成「提前复习 N 个」。建议根据实际可训练队列决定是「学习新词」「加练」还是回到内容；偏好数量不等于实际数量。
- 目前的下一批时间与数量来自词库第一页最多 100 词，不能自然解释为全词库的精确排程。没有完整排程数据时，应省略精确数量或明确是已加载数据中的提示。
- 词典摘要不是经过验证的上下文义。当前 `dictionaryPreview` 按词性和词典条目截取摘要；呈现时称为「释义」，不能直接标成「本句中的意思」。

### 真题

当前在线目录有四级、六级、考研英语一、考研英语二；列表采用平面条目，展示时间、套次、题量、建议用时和已提交成绩。作答已有题目分组、答题卡、提交确认；结果页已有错题筛选、原文、选项与解析。

- 保留现有平面目录。需要改进的是查找和状态信息，不必换成大面积试卷封面卡片。
- 作答主栏把文章放在题组之前，随后纵向展示题目；右栏主要是答题卡。长文章容易让用户在原文与后方题目之间反复滚动。
- 未接入分区仍作为可点击页签出现，进入后主要看到说明。建议在选卷前说明覆盖范围，作答中只出现真实可用题型。
- 页头、作答说明和侧栏多次重复建议用时、只做阅读、不折算分数等信息。建议每条事实留一个主要位置。
- `ExamRunner` 的答案存在组件 `useState`，交卷时统一提交；已检查的真题 API 没有草稿保存入口。当前不应展示「已自动保存」或「继续上次作答」。
- 列表只取第一页 50 套，数据超过这个范围时需要补分页或按年加载，筛选也必须匹配完整数据范围。

附带发现两处需要校正的呈现一致性：列表已隐藏考研的占位月份，作答页标题仍直接拼 `paper.month`；PDF 区「后两者暂无在线题库」的文案也与已列出的考研在线题库冲突。它们属于小范围内容修正，不需要重做页面。

## 3. 词汇页：三种形态分别放在合适的位置

| 形态 | 适合承担的任务 | 本次建议 |
| --- | --- | --- |
| 词典式多列卡片 | 搜索、浏览、管理很多词 | 留给词库；缩略呈现，展开后查完整释义 |
| 带原句的纵向词条 | 复习前找回语境，了解今天会练什么 | 作为词汇首页主体；桌面留轻量信息侧栏，手机单列 |
| 单词训练卡 | 一次回答一道题，得到反馈后继续 | 留在训练路由，避免首页直接变成长串选择题 |

### 推荐首屏

```text
词汇                                      词库 / 词单
先完成这一轮
复习 20 个 · 新词 10 个                   [开始本轮]
累计还有 86 个到期词

本轮词汇                                  学习设置
复习词                                    每日新词 10
  hesitate   /音标/   动词      [发音]     今日已学 …
  释义摘要                                来源摘要 …
  含目标词的原句
  来源标题                     [去原句]

新词
  …
```

数量仅用于示意，必须由实际接口返回值替换。首页不预先宣称训练耗时；只有明确标成建议或有可靠估算时才显示分钟数。

**信息顺序。** 词头和基础释义帮助辨认，原句帮助回忆，来源帮助返回。默认显示一到两行基础释义与一条原句，完整词典、更多上下文按需展开。考试标签只在用户筛考试词时提高权重。

**浏览与训练的答案可见性。** 首页浏览可以展示释义；进入训练后遵守题型规则：英选中可带英文原句，中选英或听辨不应被完整原句泄露答案。需要提示时由用户主动打开，后续评估是否记录提示使用；本轮不改变现有评分口径。

**来源准确性。** 有字幕锚点显示「去原句」，只有视频关系显示「去来源视频」，无来源就省略链接。片内回听需要音频与播放能力，不把现有页面跳转改名为「回听」后冒充原地播放。

**操作权重。** 一个主按钮承担开始或继续；发音、去原句为次操作；删除放进词库的更多菜单，避免抢占复习首页。

### 状态

| 状态 | 首要内容 | 主操作 |
| --- | --- | --- |
| 首次使用、词库为空 | 一句说明如何在字幕中收词，配简短操作示意 | 去看视频 |
| 本轮有到期词 | 实际复习与新词数、少量分组预览 | 开始本轮 |
| 没有到期词、有待学新词 | 明确今天无到期词，列可学新词 | 学习新词 |
| 今日已经完成 | 轻量完成反馈，保留词库入口 | 去看视频；有实际可练内容时可加练 |
| 队列请求失败 | 就地错误与重试 | 重试，不能显示成空词库或今日完成 |

短轮练习可以后续增加，但「先练 5 个」必须真的限制该轮队列并保存对应进度；仅修改按钮文案不成立。

## 4. 真题页：目录、作答、回顾各自有清晰形态

### 选卷目录：像可检索的目录

```text
历年真题 · 阅读部分
[四级] [六级] [考研英语一] [考研英语二]
年份：全部                         状态：全部

2025 年 6 月
  第一套    30 题 · 建议约 40 分钟    未作答    [开始]
  第二套    30 题 · 上次答对 21/30    已完成    [看结果] [重做]

2024 年 12 月
  …

原卷 PDF：按科目和年份查找
```

这是示意结构，不代表数据库有这些试卷或成绩。筛选属于建议新增能力。

- 默认科目可以使用已保存的目标考试；无偏好时用现有默认，不额外加必答引导。
- 年份分组有利于扫描；科目、年份、套次优先，题型构成放在组头或展开区，不在每条长篇重复。
- 已完成条目优先回看结果，并给重做入口；「看结果」需要列表能提供或可靠取得对应 session id，不能仅凭一个成绩数字拼链接。
- PDF 资源按所选科目、年份筛选或按需展开，避免把全部文件铺成很长的下载墙。专四、专八等仅有 PDF 的科目要明确标「仅原卷 PDF」。
- 「继续作答」只在恢复能力落地后出现；主按钮的优先级再调整为继续、开始、回顾。

### 桌面作答：文章与当前题组并排

```text
返回目录  |  试卷标识 · 阅读部分  |  已答 12/30  |  交卷

题型切换：选词填空 / 段落匹配 / 仔细阅读
──────────────────────────────────────────────────────
原文区（约六成）                     当前题组（约四成）
完整文章，保留段落号                 当前题干
选词填空保留词库                     选项 A / B / C / D
阅读位置随题组保留                   上一题 / 下一题
──────────────────────────────────────────────────────
答题卡：当前 / 未答 / 已答 / 待检查       建议用时 …
```

六四比例是起始候选，需用真实长文与长选项验证。优先确保两栏都可读；宽度不足时切换手机布局，不硬挤出窄列。段落匹配应持续保留段落标识，选词填空应保留可参照的词库，不能用一种普通单选排版覆盖所有题型。

只有当浏览器实际可用高度足够时，才考虑受控的独立滚动区；避免页面、文章、题组、弹层同时出现多重滚动。顶栏只保留必要状态和提交，答题卡可作为紧凑工具展开。

当前阶段继续使用「建议用时」，不画假的运行计时器。之后若加限时模式，需要完整定义暂停、离开页面、到时交卷和恢复语义。

### 手机作答：在原文与题目之间切换

- 正文保持足够宽度；「原文 / 题目」切换保留文章滚动位置、当前题号和未提交选择。首次进入先看原文，用户跳题后显示相应题目。
- 答题卡用抽屉承载，显示未答、已答、当前题；增加待检查标记时配图形和文字，不能只用颜色区分。
- 底部只放当前题相关操作，并与全站底部导航协调安全区。提交确认列出未答数量，可返回检查。
- 模式内切换必须保留状态；跨路由离开、刷新后的恢复则是独立能力，不能混称已经支持。

### 结果页：先看错题，再看依据

保留现有「答对数 / 总题数」和题型表现。下一层直接进入错题列表，每题按「你的答案 → 正确答案 → 原文依据 → 解释」排列；原文和问题保持邻近，全文按需展开。

「原文依据」需要可信证据定位。当前字段有全文和解析，不等于有经过验证的证据句；没有证据锚点时显示现有解析和原文，不伪造高亮定位。

主操作可以是「重做错题」。从原文主动选词加入词库作为后续能力，不因用户答错就自动收整段词，也不把错题直接归因为词汇不足。跨真题来源的收词契约需另核对。

## 5. 实施顺序

| 优先级 | 工作 | 依赖与范围 |
| --- | --- | --- |
| 先做 | 缩短页头、去重说明；纠正考研月份与 PDF 覆盖文案；移除作答区无可用内容的分区 | 主要是现有展示调整，仍需覆盖四种在线科目 |
| 先做 | 词汇页本轮摘要、实际队列 CTA、复习与新词分组、可靠的错误状态 | 复用现有队列，明确累计和本轮口径；不改调度算法 |
| 核心布局 | 真题桌面原文与题组并排，手机切换原文与题目 | 用真实长文、词库、段落匹配、长选项验证，保留所有答案状态 |
| 结构补全 | 真题目录年份、状态筛选与完整分页；已完成卷回结果 | 筛选须覆盖完整数据；可能需要后端查询或 DTO 支持 |
| 单独功能 | 草稿保存、继续作答、保存失败提示与恢复 | 需确定持久化、账号隔离、版本与重复提交语义，不能视为纯视觉工作 |
| 后续增强 | 待检查标记、原文高亮笔记、解析证据定位、真题收词 | 分别核对状态持久化、证据质量与词汇来源契约 |

整体延续当前浅色阅读底、深色文字和橙色主操作，不引入新的主题色或导航体系。词汇集合可保留视频缩略图；单词、试卷和解析以排版、行距、分隔线组织，不给每个对象套同样的大卡片。

## 6. 怎样验证建议有用

实施后的行为验收应包括：

- 词汇：用户能分清「累计到期」「本轮复习」「新词」；开始按钮数量与真实训练一致；有锚点和仅有视频来源都能正确返回；请求失败不会显示完成态。
- 真题：用户在读文章、选答案、打开答题卡、切题型后选择仍保留；手机无需在整篇文章和全部题目之间反复长滚；实际未开放科目不会造成入口误导。
- 长内容：真实长文章、长选项、段落匹配和词库均可完整读到；375px、桌面短视口、暗色与较大字号无遮挡。
- 数据与文案：考研不显示占位月份；目录计数与筛选匹配；得分继续使用真实答对题数；新增保存状态必须对应真实保存结果。

用户走查可围绕三个任务：开始一轮实际词汇复习；从生词找回来源句；做一组阅读并回顾一道错题。观察任务完成、迷路位置、回滚次数和状态理解，不以点击量推断掌握效果。

本轮未执行前端测试或浏览器验收，原因是仅新增调研文档、未改业务实现。上述条目是后续验收建议，尚不是通过记录。
