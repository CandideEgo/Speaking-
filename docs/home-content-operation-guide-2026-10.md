# 首页换内容操作说明（管理员日常）

> 适用：在管理后台完成「选视频 → AI 草稿 → 编辑预览 → 发布替换 → 恢复上一版」。
> 全程在站内后台完成，**不需要改前端代码、不需要重新构建或部署**。
> 实现与验证记录见 [`home-editorial-content-implementation-2026-10.md`](home-editorial-content-implementation-2026-10.md)
> 与 [`home-editorial-verification-2026-10.md`](home-editorial-verification-2026-10.md)。

当前首页采用紧凑设计：**一个视频 → 今天就能用 → 视频列表**。普通精选可直接展示任意视频的基础信息；编辑标题、词句和互动是可选的教学增强，放在「学前预览」中。以下次推配置仅用于主推失效时递补；历史「换个说法」位置不再单独显示。界面验证见 [`home-design-refresh-verification-2026-10.md`](home-design-refresh-verification-2026-10.md)。

## 0. 先弄清两个概念（避免叫混）

| 概念 | 在哪 | 作用 |
|---|---|---|
| **首页编排** | 后台「内容 → 首页编排」`/admin/home-editorial` | 选择一个主推的**已发布内容版本**；场景跟随该版本，可保留次推作为递补。 |
| **视频的「首页展示」开关** | 后台「视频管理 → 某视频 → 视频信息」 | **旧精选候选池**开关，只影响「没有新编排时」的旧首页兜底候选，**不是主推**。换新编排不需要打开它。 |

另外：视频详情里的「**首页内容**」区负责**制作一条视频的编辑内容**（标题/推荐理由/片段/表达/
互动/场景）并产生**不可变发布版本**；编排页负责**把这些版本摆到位置上**。

## 1. 日常换一条主推（最常用，1 分钟）

1. 后台打开 **视频管理 → 选中要主推的视频**（视频必须已经是「已发布 + 处理完成 ready」，有字幕）。
2. 在「**首页内容**」区：
   - 如果还没有内容：点「**生成草稿**」。AI 会在云端排队生成（页面显示 queued/running，可轮询）；
     成功后会显示字幕覆盖句数、分段数、模型和 prompt 版本。失败会显示错误码与原因，**不影响**你手工编辑。
     长字幕按原字幕边界分段提炼；超过 32 段或有单句超出模型输入能力时明确失败，不会从片头抽样后假称覆盖全文。
   - 如果已有草稿：点「重新生成」会先弹**覆盖确认**（已发布版本不受影响），确认后才覆盖草稿。
   - 不想用 AI 也可以直接手写/改草稿。
3. 编辑并**保存草稿**：
   - 标题（≤32 字）、推荐理由（≤80 字）、主题标签；
   - 依据句（从该视频真实字幕里勾选，方便对照原文）；
   - 片段起止（从字幕列表选起止句，保存后显示**服务端解析的真实时长**，可试听）；
   - 表达 1–3 条（选句 → 选原句里的词/短语 → 中文说明；短语必须真的在原句里）；
   - 互动问题 + 2–3 个选项 + 每项固定的反馈文案（主观选择，不判对错，不调用 AI）；
   - 场景 0–3 条（中文情境、提示、英语参考回复 + 中文译文），每条选择本视频的真实字幕作为依据。参考回复是教学例句，不是视频原话；没有字幕依据的场景不会显示。
   - 保存是乐观锁：若提示「内容已在别处修改」就**刷新页面**再改，系统不会静默覆盖别人的修改。
4. 点「**预览**」：直接看首页同款组件（后台看到的 = 首页显示的）。字段级问题会在预览顶部逐条列出。
5. 点「**发布并替换主推**」：一次操作同时完成「创建不可变版本 + 替换首页主推位置」。
   - 不用重新构建前端、不用重启服务；**刷新首页即生效**。
   - 若视频未公开、来源字幕已变化、字段缺失，会返回明确错误并拒绝发布。
6. 需要调整递补视频或「今天就能用」：去「**首页编排**」页选择并「**发布首页编排**」。场景只使用当前主推版本；不另外选择时自动跟随主推内容。更换主推后旧场景不会混入。

## 2. 用编排页整版调整（换次推、加场景卡）

1. 打开 **内容 → 首页编排**。
2. 分别选择：
   - **主推**：1 条（必填）；
   - **次推**：最多 2 条，作为主推失效时的递补（不能和主推是同一视频，可调整顺序；不会在首页并排展示）；
   - **换个说法**：历史配置保留，当前首页不再单独展示；
   - **今天就能用**：最多 3 条，只能选择当前主推版本的场景并调整顺序。更换主推会清除旧场景的排序引用；不设置时自动展示新主推版本的有依据场景。
   只能选「**已发布且来源有效**」的内容版本；候选列表会标出不可用原因。
3. 点「**保存编排草稿**」（不生效）。
4. 点「**整体预览**」核对。
5. 点「**发布首页编排**」：服务端重新校验可见性与来源后**原子**发布整版；有字段级问题会逐条列出，不会发布半套内容。

## 3. 恢复上一版

在「首页编排」页点「**恢复上一版**」：

- 恢复到**上一发布布局**；服务端会重新检查视频是否仍公开、字幕是否仍一致。
- 若上一版引用的视频**已下线/已取消发布**，会**拒绝恢复并说明原因**，当前线上内容保持不变。
- 若从未发布过上一版（第一次发布后想撤下新编排），恢复上一版会**撤下新编排，首页回到旧版精选兜底**。

## 4. 状态说明（视频详情的「首页内容」区）

| 状态 | 含义 | 该怎么做 |
|---|---|---|
| 未制作 | 该视频还没有草稿 | 生成草稿或手工新建 |
| 草稿 rev N | 有可编辑草稿，未发布 | 预览后发布 |
| 已发布 vN | 已产生不可变版本，且在/不在首页位置 | 需要修改就再生成/编辑，发布新版本 |
| 来源已变更 | 草稿依据的字幕被改过（编辑、重断句、重译、重新转写等） | 重新核对引用的句子与片段并**保存**，或重新生成；否则发布会因来源不符被拒 |
| 生成中（queued/running） | AI 任务在后台跑 | 等它结束；同一视频同时只有一个任务，重复点击返回同一任务 |
| 生成失败 | 有错误码与简短原因 | 可重试；也可以完全手工编辑发布（AI 不可用不阻塞发布） |

## 5. 注意事项

- 视频更换**不会**改动视频创建时间，也不需要在 React 代码里改任何东西。
- 已发布版本是**不可变**的：重新生成/编辑草稿**不会**影响线上，直到你再次发布。
- 同一视频同一时刻只允许一个生成任务；重复点击不会重复计费。
- 用户打开首页、点互动选项、收词、跟读**都不会调用 AI**；选项反馈是制作时保存好的固定文案。
- 主推/次推不会出现同一视频；失效的引用会被过滤，次推可自动提升为主推。场景跟随实际展示的主推（包括递补后的主推）；没有有依据的场景时，使用该视频真实字幕练一句，缺字幕时隐藏该区。
- 视频下线后，旧编排里的卡会立即从公共接口消失（公共接口每次读库，不走缓存）。

## 6. 普通精选兜底（无新编排时）

没有已发布编排（或全部引用失效）时，首页从「featured + learning metadata」读取真实精选与字幕；
从中选择第一条可展示视频，使用相同的单视频横卡。此时「首页展示」开关与既有精选逻辑照常工作。
发布新编排后，主推由编排决定，不再按视频创建时间决定；词句与互动在「学前预览」中展开。`frontend/src/lib/homeScenarios.ts` 只解析当前视频的内容与真实字幕，不含通用例句。普通精选使用 learning-metadata 的真实样例句、译文及定位；想增加情境练习，在该视频的首页草稿中添加有字幕依据的场景，再发布。
