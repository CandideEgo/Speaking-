## 1. 产品概述

### 1.1 定位

SeeWord 是面向中文母语者的英语学习应用。管理员精选 YouTube/Bilibili 视频，系统通过 WhisperX 自动生成双语字幕、用 ECDICT 标注考试词汇、用 AI 生成词注释。用户观看视频时点击字幕单词即可查看释义、加入词汇本，通过 SM-2 间隔重复算法复习，配合真题练习和跟读录音巩固。

**核心功能三件套**：看视频、做试卷、背单词。

### 1.2 核心学习闭环

```
浏览/搜索视频 → 观看（双语字幕 + 考试词高亮 + 点击查词 + AI 词注释）
→ 加入词汇本 → SM-2 间隔复习 / 词汇 drill / 真题练习 / 句子跟读
→ 学习记录与统计反馈（streak / 掌握度 / 里程碑）
```

系统**不派发学习任务**，不规定"今天必须学什么"。用户自主决定学习内容，系统只记录行为并提供反馈和便利入口。

### 1.3 考试词汇体系

| 级别 key | 标签 |
|---|---|
| zhongkao | 中考 |
| gaoKao | 高考 |
| cet4 | 四级 |
| cet6 | 六级 |
| ky | 考研 |
| ielts | 雅思 |
| toefl | 托福 |
| gre | GRE |

用户在 onboarding 或个人中心设置目标考试级别（`UserPreferences.target_exam`），观看页按该级别过滤高亮词汇。

## 2. 用户角色与权限模型

### 2.1 角色定义

| 角色 | 判定 | 说明 |
|------|------|------|
| 游客 | 无有效 JWT | 无法访问任何产品页面，统一跳转登录页 |
| Free 用户 | 已登录，`plan=free` | 每月可解锁 3 个视频，解锁后永久可看 |
| Pro 用户 | 已登录，`plan=pro` 且 `plan_expires_at > now` | 无限解锁所有视频 |
| 试用用户 | 注册后自动获得 3 天 Pro（`plan_source='trial'`） | 与 Pro 权限相同，到期自动降 Free |
| 管理员 | `role=admin` | 管理后台全部权限 |

### 2.2 路由访问矩阵

| 路由 | 游客 | Free | Pro | 管理员 |
|------|------|------|-----|--------|
| `/login` `/register` `/forgot-password` | ✅ | ✅ | ✅ | ✅ |
| `/terms` `/privacy` | ✅ | ✅ | ✅ | ✅ |
| `/upgrade` `/redeem` | ✅ | ✅ | ✅ | ✅ |
| `/` 首页 | → /login | ✅ | ✅ | ✅ |
| `/browse` `/search` `/channels` | → /login | ✅ 可浏览 | ✅ | ✅ |
| `/watch/[id]` | → /login | 需解锁（见 §4） | ✅ | ✅ |
| `/vocabulary` `/practice/*` `/history` `/favorites` `/profile` `/contact` | → /login | ✅ | ✅ | ✅ |
| `/onboarding` | → /login | ✅ | ✅ | ✅ |
| `/admin/*` | → /admin/login | ✗ | ✗ | ✅ |

`/pricing` 重定向到 `/upgrade`。`/checkout` 保留（支付代码 dormant，待 ICP 启用）。

### 2.3 Free 与 Pro 的唯一区分

**视频解锁数量是 Free 与 Pro 的唯一权限差异。** 一旦解锁某个视频，Free 用户在该视频内享有与 Pro 完全相同的功能：双语字幕、词卡查词（含 AI 词注释）、跟读录音、真题练习、词汇复习等，不做任何功能阉割。

## 3. 账号与认证

### 3.1 注册

- 手机号 + 短信验证码注册（阿里云 SMS，无邮箱注册）
- 注册时可设置密码（也可后续在个人中心设置）
- 注册成功后**自动发放 3 天 Pro 试用**（`plan=pro`、`plan_expires_at=now+3天`、`plan_source='trial'`）
- 每个手机号仅一次试用
- 注册后引导 onboarding（见 §5.11），完成后进首页

### 3.2 登录

- 手机号 + 短信验证码，或手机号 + 密码
- JWT 双 token（access + refresh），access 过期自动刷新
- 登录后跳转回 `next` 参数指定的原页面

### 3.3 忘记密码

三步向导：手机号验证 → 验证码校验 → 设置新密码。

### 3.4 登出

清除本地 token，跳转登录页。

## 4. 会员与视频解锁机制

### 4.1 Free 解锁规则

- Free 用户每月有 **3 次解锁机会**，每月 1 日 0 点刷新
- 用户主动选择视频解锁，解锁后该视频**永久可看**（随时回看，不重复消耗）
- 当月未用完的次数不累计到下月
- 已解锁视频不随次月刷新而锁定
- 浏览视频列表/搜索/查看视频信息不消耗次数，只有点击"解锁并观看"才消耗
- 同一视频重复观看不重复消耗
- 试用期间（Pro 身份）观看的视频不写入解锁记录；试用结束降 Free 后需重新解锁

### 4.2 解锁流程

1. Free 用户在首页/浏览/搜索点击未解锁视频 → 进入 watch 页
2. watch 页播放器区域显示**解锁面板**：视频标题/频道/难度/时长 + "解锁后可随时观看，不重复消耗" + 本月剩余次数 + [解锁并观看] 按钮
3. 点击"解锁并观看" → 后端创建解锁记录 → 播放器加载 → 开始播放
4. 本月 3 次用完后，解锁面板切换为**升级引导态**："本月 3 次解锁已用完" + Pro 权益列表 + [输入兑换码激活] + "下月 1 日恢复 3 次"
5. 已解锁视频：列表卡片显示"✓"角标，进入 watch 页直接播放

### 4.3 Pro 会员

- 价格：¥9.9/月，30 天/码
- 获取渠道：微信小商店购买 → 获得兑换码 → 在 `/redeem` 或 `/upgrade` 输入激活
- 兑换码可叠加续期（多码顺延）
- Pro 到期由 beat 任务自动降为 Free，已解锁视频不受影响
- 试用期间输入兑换码，有效期顺延到试用结束后

### 4.4 兑换码生命周期

- 4 态状态机：`unused → redeemed / revoked / expired`
- 一张码 = 30 天 Pro
- 核销：行锁防并发（`with_for_update`）
- 退款撤销：码置 `revoked` + 扣回 30 天 + 必要时降 Free
- 管理员后台可批量生成、导出 CSV、撤销

### 4.5 在线支付

- 当前 ICP 合规阶段：`payments_enabled=false`，站内不收款
- 支付代码（支付宝/微信支付 create-order、callback、订单对账 beat 任务）保留 dormant，ICP 营业执照落地后开关启用
- 启用后兑换码保留为礼品/活动渠道

## 5. 功能需求

### 5.1 首页 `/`

**定位**：用户打开 App 的第一屏，快速开始学习。

**内容**：
- 问候语（按时段：早上好/下午好/晚上好）+ 日期
- 紧凑统计行：连续天数 · 词汇量 · 已学视频数（纯展示，无目标进度）
- "开始复习"按钮（仅有到期词汇时显示，进入词汇 drill）
- 分类筛选栏：推荐/TED Talks/Interviews/News/Vlogs/Educational/Movie Clips/Tech/Speeches + 难度（全部/A1-C2）
- 视频网格（无限滚动）
- 新里程碑达成时显示顶部横幅（可关闭）

**不显示**：今日任务清单、完成进度环（0/6）、AI 计划生成入口。

### 5.2 视频发现

#### 5.2.1 浏览 `/browse`
- 页头"浏览视频"
- 频道条（ChannelStrip，有频道时显示）
- 分类 + 难度筛选
- 视频网格 + 无限滚动

#### 5.2.2 搜索 `/search`
- 顶部搜索框（占位符"搜索视频、字幕、单词..."）
- 聚焦时显示热门搜索（按播放量 Top 10）
- 输入 ≥2 字显示搜索建议（视频标题前缀匹配，防抖 300ms，键盘可导航）
- 搜索历史（localStorage 最近 10 条，可删）
- 搜索范围：视频标题 + 字幕内容
- 无结果时显示推荐视频

#### 5.2.3 频道 `/channels`、`/channels/[slug]`
- 官方策展频道（管理员维护名称/封面/简介/排序/显隐）
- 频道页展示该频道下视频
- 频道与分类/标签正交，一期不做订阅

### 5.3 视频观看 `/watch/[id]`

SeeWord 的核心页面。

#### 5.3.1 播放器
- 自定义控制条（替换原生 controls）：
  - 播放/暂停（空格）、快进快退 10s（←/→）、进度条
  - 音量（↑/↓/M）、全屏（F）
  - 倍速：0.5/0.75/1/1.25/1.5/2（C 键切换，localStorage 记忆）
  - 字幕显示模式：双语/仅英文/仅中文/隐藏（S 键循环）
  - 字幕字号：小/中/大（写入 preferences）
- 移动端控制条 3s 自动隐藏，倍速/字幕收进"更多"弹层
- 支持 YouTube iframe 嵌入（轻量模式）和本地视频文件

#### 5.3.2 字幕区
- 双语字幕逐句显示，当前句高亮
- 英文字幕单词可点击，点击弹出词卡
- 考试级别词汇按用户目标考试高亮
- 字幕独立滚动，当前句自动跟随

#### 5.3.3 词卡（点击单词弹出）
- 音标、词性、英文释义（ECDICT）、中文翻译（ECDICT）
- AI 词注释（管线预热，含语境释义/常见误区/用法扩展）
- 真题例句 + 高频词标记（exam_corpus）
- "加入词汇本"按钮
- 首次加词有金色高光反馈
- 词卡数据来源：ECDICT 本地（即时）→ word_ai_notes 预热缓存 → 真题语料。**不实时调用 AI**（缓存未命中时降级为纯 ECDICT）

#### 5.3.4 视频信息与操作
- 标题、频道、难度（CEFR）、时长
- 点赞按钮（显示点赞数，like_count 喂推荐因子）
- 收藏按钮（Bookmark，加入"我的收藏"）
- 笔记按钮（Pencil，打开笔记抽屉，每视频一条笔记，最多 10000 字）
- 词汇本快捷入口
- Fork 标记（仅当视频为副本时显示）

#### 5.3.5 跟读（Shadowing）
- 选择字幕句 → 录音 → 回放对比
- 录音自动上传持久化（`media/shadowing/{user_id}/`，owner-only JWT 鉴权）
- 自评：满意/一般（无 AI 评分）
- 跟读历史列表面板
- 写 LearningEvent（shadowed_sentences）

#### 5.3.6 练习区
- 默认折叠为"开始本句练习"CTA（渐进披露）
- 展开后显示当前句相关练习题（选择题等）
- 作答后即时反馈，更新 SM-2 掌握度

#### 5.3.7 视频结束面板
- 视频播放到末尾时显示（不自动跳转）：
  - 本节统计：观看时长、查词数、加词数
  - [复习本视频生词] → 词汇 drill，只练本视频词
  - [跟读重点句] → 跟读面板，自动选 3 句考试词密度最高的句子
  - [返回首页]
- 可关闭重看

#### 5.3.8 新手引导
- 新用户第一次进入 watch 页时触发 Coach Mark 动画（遮罩挖洞 + 聚光灯 + 气泡）
- 4 步：点字幕查词 → 加入词汇本 → 练习/跟读 → 结束
- 可跳过，localStorage 记忆不重复

### 5.4 词汇本 `/vocabulary`

#### 5.4.1 词汇列表
- 展示用户加入的所有单词
- 按 SM-2 状态筛选：全部/待复习/已掌握/学习中
- 排序：加入时间/下次复习时间/掌握度
- 每个词显示：单词、音标、释义、掌握度、来源视频
- 支持删除（即时删除 + Undo toast 5s）
- 空状态引导去看视频

#### 5.4.2 词汇复习（SM-2）
- 三档反馈：忘了/模糊/记住了（键盘 1/2/3 快捷键）
- 根据 SM-2 算法更新 ease_factor、interval、next_review_at
- 全屏 drill 模式 `/vocabulary/drill`：进度条 + 居中题区，默认只练到期词

#### 5.4.3 词汇练习（多题型）
- 6 种题型轮换：英译中、中译英、选词填空、拼写、例句搭配等
- 作答后即时判分，更新 SM-2 + LearningEvent
- 结果汇总：正确率、用时、错词列表
- 答错的词若有来源视频，显示"回看原句"链接（跳转 watch 页定位高亮）

### 5.5 练习与考试 `/practice`

#### 5.5.1 练习中心
- 每日检测（跨视频抽题）
- 真题试卷列表（按年份/类型，服务端判分，答案不下发）
- 错题本入口
- 最近观看视频的"本视频真题"卡片

#### 5.5.2 真题考试
- 三种模式：
  - `paper_exam`：完整真题卷（选择真题试卷 → 答题 → 交卷 → 判分）
  - `daily_check`：每日检测（跨视频随机抽题）
  - `wrong_redo`：错题重做（只练错题，答对即销账）
- 试卷运行器（ExamRunner）：
  - 倒计时（默认 30 分钟，<60s 警告色）
  - 退出按钮、移动端底部提交栏、选项两列网格
  - 服务端判分，交卷后复用 SM-2 更新
- 结果页：分数、正确率、错题回顾、[只练错题]/[再做一遍]/[再练一套]

#### 5.5.3 错题本
- 派生查询（不另建表）：最近一次作答仍错的题才在错题本
- 重做答对即销账
- 统计：错题数、正确率趋势

### 5.6 学习记录 `/history`

- 学习记录列表（按日期分组：今天/昨天/更早）
- 每条记录：视频标题、观看时长、学习时间、状态（学习中/已完成）
- 筛选：全部/学习中/已完成
- 顶部统计卡：总视频数、总时长、连续天数、已掌握词汇
- 点击记录跳转对应视频

### 5.7 个人中心 `/profile`

#### 5.7.1 个人资料 Tab
- 用户卡：头像、昵称、Pro 标识、手机号掩码、目标考试、加入天数
- 统计：已学视频数、掌握词汇数、连续天数
- 编辑昵称、头像、密码

#### 5.7.2 学习进度 Tab
- 掌握度趋势图（8 周，手写 SVG 线图）
- 词汇量增长曲线（mastery_snapshots）
- 学习日历热力图（30/90 天，GitHub 贡献图样式）
- 各类型事件占比（观看/词汇/练习/复习环形图）
- 周循环 4 格（观看/词汇/练习/复习，当天完成点亮，4 格全亮有庆祝动画）
- 成就徽章墙（里程碑网格）

#### 5.7.3 设置 Tab
- 目标考试级别
- 每日学习时长（仅参考，不驱动任务）
- 字幕字号偏好
- 提醒设置：复习提醒开关 + 时间、streak 保卫提醒、Pro 到期提醒
- 深色模式跟随系统
- 意见反馈入口
- 退出登录

### 5.8 收藏 `/favorites`

- 用户收藏的视频网格（复用 VideoCard）
- 按收藏时间倒序
- 卡片显示"已收藏"角标；有笔记的视频显示笔记摘要（前 60 字）
- 点击笔记摘要跳转 watch 页并自动打开笔记抽屉
- 取消收藏：乐观更新 + Undo toast
- 空状态引导

### 5.9 反馈与公告 `/contact`

- 公告区：系统公告列表（管理员发布）
- 反馈表单：分类（问题/建议/其他）+ 内容，提交后管理员后台可见
- 入口：TopBar 头像菜单 + Profile 设置页

### 5.10 升级与兑换

#### 5.10.1 升级页 `/upgrade`
- Pro 权益说明（无限解锁所有视频）
- 三步指引：微信小商店购买 → 复制兑换码 → 回站激活
- 兑换码输入框（支持 URL 参数自动填充）
- 合规告知

#### 5.10.2 兑换页 `/redeem`
- 输入兑换码 → 核销 → Pro 开通/续期
- 行锁防并发

### 5.11 新手引导 Onboarding `/onboarding`

3 步（可跳过）：
1. 水平选择：A1/A2/B1/B2/C1
2. 学习目标：四级/六级/雅思/考研/高考/日常提升
3. 学习节奏：每日时长（15/30/45/60 分钟）+ 兴趣话题（科技/商业/教育/文化/生活/新闻，多选）

完成后进首页。兴趣话题用于推荐冷启动。

### 5.12 管理后台 `/admin`

| 模块 | 功能 |
|------|------|
| 仪表盘 | 实时在线人数、核心指标 |
| 视频管理 | 视频列表、提交 URL 处理官方视频、字幕编辑器（reorder/新建/删除/时间轴/词级标注/重分段）、重试/恢复/重翻、质量报告、频道归属 |
| 频道管理 | 创建/编辑/排序/封面/显隐 |
| 用户管理 | 用户列表、封禁/解封、改会员、查看学习数据 |
| 订单管理 | 订单列表（支付启用后） |
| 兑换码管理 | 批量生成、导出 CSV、撤销、状态查看 |
| 反馈公告 | 查看用户反馈、发布/管理公告 |
| 数据统计 | 用户/学习/兑换码 KPI、漏斗报表 |
| 系统设置 | 平台参数 |

管理员登录独立会话（`seeword_admin_token`，与用户端隔离）。

## 6. 视频管线（后端）

管理员提交视频 URL 后，异步管线处理：

```
Head（云端）：提取元数据 → 封面本地化 → 入队 GPU
  → GPU Worker：WhisperX 转录 + wav2vec2 强制对齐（无 DB/OSS 凭证，HTTP 回调）
  → Tail（云端）：翻译（双引擎并发 + 指数退避重试 + 质量门）
    → ECDICT 考试词汇标注 → AI 词注释批量预热 → 下载转码（480/720/1080p）→ 标记 ready
```

- 断点续传：Redis 记录已完成步骤，重入跳过
- 幻觉检测：转录回调时检测重复/无意义/时长不匹配，失败标记 error
- 翻译质量门：覆盖率/短比/中英混杂/长度异常检测
- 标准版去重：同一 source_url 首个 ready 视频为标准版，避免重复 GPU 处理
- 媒体文件存后端本地卷（`LOCAL_MEDIA_PATH`），Nginx range 代理 `/media/`
- 外部封面入库时本地化下载，渲染不依赖外部 CDN

## 7. 通知系统

- 站内通知 + WebSocket 实时推送（best-effort）

  - 学习提醒：到期词汇复习提醒（用户设定时间，默认 20:00）

## 9. 非功能需求

### 9.1 性能
- 首屏加载：骨架屏（ShellSkeleton），不使用全屏 Spinner
- API 响应：P95 < 500ms（不含视频流）
- 视频流：range 请求支持，Nginx 缓存
- Redis 全部依赖 fail-open，Redis 故障不阻塞主流程

### 9.2 安全
- JWT 鉴权（PyJWT），密码 bcrypt 哈希
- 媒体文件 owner-only JWT 鉴权（跟读录音）
- 上传文件扩展名白名单 + nosniff
- `/media/proxy` SSRF 防护（禁重定向、域名白名单）
- 全局限流（Redis，故障降级 in-memory）
- 后端容器非 root + HEALTHCHECK
- GPU Worker 无 DB/OSS 凭证（安全边界）

### 9.3 兼容性
- 桌面：Chrome/Edge/Firefox/Safari 最新两个大版本
- 移动：iOS Safari、Android Chrome
- 响应式：移动端底部 TabBar（5 项：首页/浏览/练习/词汇/我的），桌面水平导航
- 深色模式：CSS 语义变量，`.dark` 块自动级联

### 9.4 可访问性
- 所有交互元素键盘可达，focus 可见
- 播放器快捷键：空格/←→/↑↓/F/S/M/C
- 考试词高亮不仅靠颜色（加下划线/圆点）
- 图标按钮带 aria-label
- Lighthouse a11y ≥ 90

### 9.5 合规
- ICP 备案前不启用在线支付，仅兑换码渠道
- 隐私政策/服务条款页面
- 用户数据：跟读录音 owner-only，不公开
- SMS 验证码登录，无邮箱

| AI 助手（AI 查词/AI 总结/AI 推荐对话） | 前端零调用，权益复杂 | 2026-08-27 决策 |
| 营销落地页 | 登录墙模式，首页即产品 | 2026-08-27 决策 |
