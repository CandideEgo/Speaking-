# 首页设计改造验证（2026-10-20）

本轮按用户最新反馈进一步精简真实首页：集中操作组、一个通用视频位、本期视频关联练习、视频列表。复用既有内容维护系统；未部署生产。

## 已完成

- 删除标语、重复分区标题、重复来源行和截断的长提示。只留「今日精选」页头，续学/复习/找视频集中在同一按钮组，续学视频与位置放进提示。
- `HomeVideoFeature` 统一普通精选和已发布内容：只显示一个视频，封面与标题横排；来源、难度、时长、简述按实际数据展示。标题最多两行，无教学元数据也能观看。
- 词卡、真实原句、互动、试听、跟读、文稿放进默认关闭的「学前预览」；原声失败仍能在预览关闭时显示重试入口。
- 「今天就能用」只跟随当前主推版本，最多三卡。卡片只显示情境、表达、译文与「试一句」，完整提示放进练习弹窗。跨视频和旧版本的编排引用不会混入；无手动排序时自动跟随新主推的场景。
- 删除三条内置通用例句。无有依据场景时，使用当前视频的真实字幕做练一句，原句/译文/时间/跟读定位都来自同一来源；没有可用字幕则隐藏。编辑场景参考回复与字幕原话在弹窗中区分，不调 AI、不写学习记录。
- 后台编排只能选择当前主推版本的场景；更换主推会清掉旧场景排序引用。次推仍保留后端递补用途，不并排展示。
- 「先复习 5 个词」进入最多 5 个到期词的小轮练习，使用既有 practice 接口，不改变每日训练配额；不足 5 个时首页显示实际数量。
- 无进行中记录、无到期词、取数失败、无媒体和无编排均有真实可用的入口或兜底。
- 分类、难度、排序原地更新：URL 替换禁止默认回顶；首页内换条件只记录当前偏移，不恢复该条件过去的旧位置。刷新/重新进入页面仍按当前 URL 恢复。空结果保留一屏列表高度，防止容器收缩带走工具栏。

当前本地库没有发布首页编排，真实页面展示 Bob 普通精选与该视频的一条真实字幕练习；未为截图发布示例视频或调用 AI。已发布编排的情境练习与换视频联动由测试数据另外验证。

浏览器检查覆盖：单视频且默认收起、集中入口、已发布内容的互动/收词/定位、原声范围及失败状态、少量到期词、短复习请求参数、普通精选兜底、长标题/缺元数据展示、换视频后场景联动及来源链接、场景输入/参考表达/关闭和焦点恢复、390/320 无横向溢出、真实内容流筛选请求和旧链接跳转。真实数据用例额外检查浏览器无 pageerror/console error。

高度预算通过：1440 桌面精选卡 ≤275px、快捷入口 ≤65px；默认桌面和 390 手机的 `#feed` 顶部均 ≤700px。预算只针对默认收起状态，用户主动展开教学内容后可以增高。

本轮发现精选卡与关联场景组件的同级 key 重复，已使用各自前缀修正，并用真实页面的浏览器错误检查验证；未改动推荐取数逻辑。旧标题与固定三例句的测试断言已按新需求同步；未放宽检查器或高度预算。

追加的滚动回归在修复前复现两次明确失败：分类后 `scrollTop` 从 324 变为 0；只关掉默认回顶后，已保存的同条件旧位置又把 324 拉到 1400。修复同时处理 URL 导航和按 query 恢复的介入时机。1440/390 用例覆盖分类、难度、排序、旧存档、刷新恢复及空结果；几何用例使用固定接口响应，真实后端读取和浏览器错误检查另行保留。

「今天就能用」已接入分段全文提炼、字幕锚点与表达复用校验、后台覆盖度记录和展示，实施边界见[执行方案第 13 节](home-editorial-content-execution-plan-2026-10.md#13-今天就能用全文提炼实现记录2026-10-20)。本轮未调用真实模型、发布内容或部署；自动测试与完整生成发布闭环未执行。

真实数据检查通过本地开发后端及前端代理，注册测试账号读取实际精选与字幕；新复习请求校验 `count=5&due_only=true`。没有批量清理或发布编排。

后端测试、全量后台发布闭环、生产验收未执行；全量闭环脚本的展示断言已同步到单视频/按需预览/场景弹窗，但该脚本本轮未执行。新增的生成覆盖迁移尚未应用；本轮没有调用真实模型或发布线上内容。此前内容维护闭环的验证记录不计入本轮通过数量。
