## 测试环境与记录要求

1. 仅本地开发或明确隔离的测试环境；使用测试账号与现有登录工具。不得改真实线上账号、权益、支付或业务数据。
2. 三类证据分别记录：受控响应验证异常/竞态；本地真实媒体验证播放与时间；人工原声听校验证内容语义。不能互相替代。
3. 真实媒体优先用经过人工抽检的本地素材；合成的可播放媒体可用于确定性边界测试，但不能证明字幕质量。
4. 基础视口：1280×720、1440×900、390×844、375×667；320 窄屏作为结构压力检查。手机浏览器优先 iOS Safari / Android Chrome 实机，浏览器模拟单独标注。
5. HTML5 和 IFrame 分别建记录；本地播放成功不代表第三方后端通过。现有 Firefox 与 Chromium 重要路径均需按可用环境验证。
6. 每条记录保存：用例号、版本/环境、视频与锚点、前置状态、动作、期望、实际、通过/失败/未执行/不适用、截图或日志、复现步骤。未知不得记为通过。

## AC-01 内容基线

- [ ] **01-A 来源与可用性**：对样本视频核对标题、来源和实际可播媒体。开始播放后确有音画推进；只有媒体 URL 非空不算通过。来源、授权或可持续供给信息未核实的项目单列运营待办，不臆造许可。
- [ ] **01-B 30 个锚点听校**：10 条视频各取首句、长句/碎片句、末句。逐个听原声并核对完整意思、起止时间、中文译文。失败项记录真实内容与更正建议，不修改线上字幕。
- [ ] **01-C 降级**：分别提供无字幕、无译文、内嵌文字的样本。页面如实说明限制：无字幕仍能普通观看、无译文保留英文、隐藏站内文本不宣称隐藏了原视频文字。

当前 [samples.json](samples.json) 仅含 10 条候选和各 1 个公开预览，时长约 121～771 秒，候选语速字段缺失。不能据此宣称语速覆盖或已完成 30 个定位点。用 [listening-checklist.csv](listening-checklist.csv) 补齐人工核对：30 行代表待执行任务，不是 30 条已通过的句子。

## AC-02 播放、暂停、拖动与当前句

- [ ] **02-A 状态一致**：可播放样本中连续操作播放/暂停 5 次；断言实际 paused/playing 与按钮、时间推进一致，无重复播放命令或浏览器未处理的拒绝。
- [ ] **02-B 快速导航**：在首/中/末位置连续拖动，再点上一/下一句；以最新动作的目标为准，当前句随实际媒体更新，不能停在旧句或被早期 seek 拉回。
- [ ] **02-C 倍速与缓冲**：至少 0.75x/1x/2x 重复暂停和定位；人为缓冲期间保留正确目标和恢复操作，不能把 waiting 状态误当播放已经推进。
- [ ] **02-D 双后端与设备**：HTML5 和 IFrame 各执行核心控制；手机旋转、前后台切换与短视口检查播放入口仍可点。第三方限制记录为未解决问题，不静默排除。

## AC-03 本句定位与区间重听

- [ ] **03-A 基本行为**：从任意播放位置点击「重听本句」，按可靠 start/end 播放一次，句末暂停；目标句身份保持，按钮恢复到可重听状态。
- [ ] **03-B 不混淆跳句**：点击文稿某行，应从该行开始连续播放；UI 不把它标为「只听这一句」。
- [ ] **03-C 边界**：验证首句、末句、短句、长句、两句无间隙、两句有间隙。不得截断首尾词，也不应明显带入下一句。语义残句需要内容修正或明确降级。
- [ ] **03-D 取消旧任务**：播放 A 的本句区间时切到 B、拖进度、再发一次重听或离开页面。旧 A 的结束监听不得暂停/跳回 B。
- [ ] **03-E 自动播放限制**：浏览器拒绝 play 时保持已确定的目标并显示可点播放入口，不显示「正在重听」假状态。

技术建议（待按后端校准）：受控媒体记录实际起点误差和句末超出量，初始目标可取起点绝对误差 ≤0.25 秒、停止超出 ≤0.5 秒；同时必须满足人工“不截断/不明显带入下句”。这些数值是工程预算提议，不替代 AC 原意，不能靠放宽误差掩盖不可听的边界。若 IFrame 无法满足，先提交限制与替代体验评审。

## AC-04 英文、译文、词义与关闭帮助

- [ ] **04-A 同词不同句**：在 Bob 第 202 行点击 walk；词卡、上下文请求与可选收词数据都对应此次被点句，不指向首次出现的第 189 句。再在另一行点同词验证上下文确实切换。
- [ ] **04-B 帮助进出**：按已评审的暂停策略打开帮助，核对目标句与媒体位置；关闭按打开前的播放状态恢复；原本暂停保持暂停，重听恢复剩余区间至句末。新操作优先，关闭不 seek、不恢复旧位置。
- [ ] **04-C 请求乱序与关闭**：慢速点击 A 后快速点击 B；仅 B 可更新。请求未完先关闭，完成后不重开词卡、不重新发音。
- [ ] **04-D 局部失败**：静态释义失败显示错误/重试/关闭；增强释义失败保留已有基础内容；无词条与网络失败分开。
- [ ] **04-E 音频与键盘**：词典发音由显式动作触发；播放原声时无重叠发音。通过键盘完成进入帮助、关闭和重听，焦点回到可预期位置；读屏能识别模式及按钮名称。

## AC-05 获取帮助 → 减少辅助 → 再听

- [ ] **05-A 连贯路径**：双语查看帮助后，选择「少一点辅助再听」；词卡关闭，译文隐藏，目标原声播放。无需收词、评分或离开页面。
- [ ] **05-B 全部呈现面一致**：隐藏英文时检查当前句、全文文稿、词卡及可访问文本，避免站内另一处继续露出应隐藏的学习文本。原片内嵌文字另作说明。
- [ ] **05-C 偏好不污染**：本次重听结束仍保持临时减少状态；点恢复可回到原偏好；换句/继续播放清理临时覆盖。刷新后长期偏好不被此次临时操作改写。
- [ ] **05-D 所有起始模式**：双语→英文，英文/中文→关闭，已关闭则保留关闭并重听。用户显式切模式时尊重最新选择。
- [ ] **05-E 自由观看**：没有查看帮助、没有重听或没有收词的用户，也能正常继续或退出；没有强制自评/完成弹窗。

## AC-06 离开续学与显式锚点

- [ ] **06-A 短会话**：播放 3～5 秒后暂停、立即站内离开；服务端确认保存后，用「继续学习」恢复最后确认位置。不能只测超过 10 秒的长播放。
- [ ] **06-B 深链对抗慢续播**：已有位置 120 秒；本次目标 30 秒；将历史 GET 延迟至目标定位后返回。最终仍在 30 秒，不被 120 秒覆盖。两种响应顺序都测试。
- [ ] **06-C 主动操作优先**：等待恢复时用户拖到 45 秒，晚到历史数据不能带走位置；加载元数据期间多个 seek 只应用最新有效命令。
- [ ] **06-D 首几秒记录**：保存位置 2 秒、0 秒、接近结尾分别测试；不得因固定 >5 秒条件丢失可恢复的短观看意图。结尾提供再看/从头选项，不自动等同听懂。
- [ ] **06-E 失败及写入顺序**：保存失败可见且允许退出/重试；旧请求晚完成不得覆盖更新位置。不显示未经服务器确认的跨设备保存成功。
- [ ] **06-F 标签页与跨设备**：后台切换、刷新、关页单独记录能力边界；跨设备读到服务端最后确认位置。浏览器强杀无法保证的情况明确写出，不用本地缓存伪装成服务器成功。

位置准确性以媒体元数据与实际保存精度验证；先记录误差，再审定预算。不要用观看比例或“已学会”作为恢复是否正确的断言。

所有用例均要求有可达返回出口，且不删除收藏、笔记、生词或观看记录。

## AC-08 既有业务回归与范围保护

- [ ] **08-A 词汇**：已收生词、已有词单与复习可进入；可选收词仍按真实目标保存。此次观看未收词也能结束。
- [ ] **08-B 真题**：原题型/套卷能进入和作答，提交后解析可读；不新增题型或改变判分。
- [ ] **08-C 收藏**：视频/句子收藏状态不丢；取消视频收藏不联动删除生词/笔记；下架记录可解释。
- [ ] **08-D 登录**：深链经登录后保留原任务，现有会话写入门通过；不绕过权限。
- [ ] **08-E 会员**：读取既有套餐和会员状态可用；对修改范围、请求与代码差异检查，确认未改变价格、权限、支付。不要为验证而真实付款或开通会员。
- [ ] **08-F 已删除功能退出新路径**：进入、查看帮助、重听、结束时无录音入口、无麦克风权限请求、无旧录音 API 自动调用；不新增热力图、成就、周报或复杂任务依赖。历史数据不删除。
- [ ] **08-G 全站规范**：设计 token、容器归属、会话写入、类型与 lint 等按仓库门禁；不改检查器/豁免来通过。

## 约 5 位用户的任务试用

使用经过听校、适合被试理解水平的材料；允许用户换一个感兴趣的视频，不教授按钮。记录是否独立完成、用时、求助次数、原话与失败位置。

1. 从现有入口找到愿意看的内容并播放。
2. 找到一句不懂的话，在播放器内得到帮助。
3. 减少一种辅助，重听刚才那句。
4. 离开后通过继续找回位置。

沿用 v2 的探索门槛：每个任务至少 4/5 人无需引导完成；多人重复的大困惑先修复再测。可询问「比刚才更能听出来吗」，只作自评与质性证据。不能把用户点了再听就统计为听懂。

本轮未招募或执行真实用户试用，不能填造结果。

## 最小度量与放行

先用受控测试和人工记录建立基线，不为本轮设计新增埋点实现。之后如需产品事件，记录最少的播放成功、帮助打开/失败、目标句重听启动/结束、续学命中/失败和异常类别；不采集笔记正文或私密学习文本。

- 首次有效观看率：真正开始播放的有效观看访问 / 进入观看页的有效访问；不能只看点击。
- 帮助后重听率：查看帮助后能重听同一目标的会话 / 使用帮助的会话；不等同理解率。
- 恢复成功率：恢复到最后有效确认位置的请求 / 主动继续请求。
- 障碍率：按媒体、字幕、词义、定位、保存分别统计，避免合并后掩盖原因。
- 真正理解的变化，通过用户任务和可选自评探索；观看进度、看完率和收词数量不能替代。

设计评审通过，只授权进入后续实施讨论；不等于产品放行。实施后 AC-01～08 无严重阻断、测试记录可复查、完成最小用户试用，才满足 v2 的 P0 迁移资源门槛。当前阶段只交付设计和基线。
