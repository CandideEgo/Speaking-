# SeeWord 观看基线：实施与验证记录

日期：2026-10-21。实施依据为用户确认的前后端方案；基于本地工作区，未部署生产。本文件记录工程结果，不宣称字幕质量或学习效果已经通过验收。本地前端 :3000 与开发 API :8000 已恢复，登录页和 API 健康检查均为 200；本轮专用测试数据库已全部清理（剩余 0 个）。

## 已实现的观看闭环

选择视频 → 连续观看 → 点当前句单词 → 暂停并查看帮助 → 关闭后恢复原播放状态，或减少辅助并重听本句 → 句末暂停 → 继续观看／离开续学。

- 画面下方直接展示当前句；上一句、重听本句、下一句、继续播放为主操作，收词、收藏与笔记保持次级。手机播放控制仍在内容区，保留全站导航。
- 「重听本句」使用字幕 start/end，句末暂停；点击文稿行从该处连续播放。换句、拖动、切视频取消旧区间和尚未完成的定位。独立边界时钟不依赖 React 字幕刷新。定位确认时即武装区间，避免极短句在首个时钟采样前已结束而漏停；增加极短句回归。
- 打开词卡暂停；关闭恢复打开前状态。原本暂停保持暂停，原本重听恢复剩余区间至句末。新播放、暂停、定位使旧帮助恢复失效。词典发音改为手动；恢复原声前停止词典声音，浏览器不支持发音时仍能查词和重听。
- 点词捕获当前渲染句子的 ID、起止和文本；查词、词卡来源、收词共用该上下文。响应通过序号与 AbortController 隔离，关闭、换词和切视频后不接受过期结果。基础词典与增强内容分别展示失败与重试。
- 首访保留双语，已有偏好保留。减少辅助为内存覆盖：双语→英文，英文／中文→关闭；当前句、文稿与词卡同步减少，原已打开词卡关闭；用户之后主动点词仍能再次求助，关闭后继续剩余区间并保留本次字幕模式。手动暂停和句末停止保留临时模式；继续、换句、拖动或切视频恢复。主动选择字幕模式覆盖临时模式，按钮与 S 键按当前可见模式循环。
- 分开显示加载、缓冲、暂停、结束与失败；提供媒体重试、词义重试、空字幕普通播放、失效锚点的明确说明与备用位置选择。点词可键盘操作，关闭后恢复触发词焦点。
- WebKit 回归发现并修复两项兼容问题：缺少 SpeechSynthesis 导致词卡初始化异常；初次媒体定位被浏览器重置时，在定位命令仍有效的情况下进行一次受控重试，仍失败则明确提示。

## 后端与保存契约

| 能力               | 实现与兼容边界                                                                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET/PATCH 观看进度 | 请求、响应不变，无迁移；保存逻辑提取到 `watch_progress_service.py`。负数、非有限值仍拒绝，已知时长时限制上界。只更新观看位置、访问时间与观看比例，不写「听懂／掌握」。     |
| 首次并发创建       | INSERT 在嵌套事务内进行；唯一键竞争失败后重新锁定记录，并应用当前请求位置。真实 PostgreSQL 测试验证此分支和四请求首次保存。                                                |
| 前端保存           | 每视频一个串行队列，一个进行中请求、一个最新待保存值；最短 2200ms 间隔，合并、去重；暂停、定时、隐藏、pagehide、站内卸载共用队列。失败可见且不阻止退出，下一触发机会重试。 |
| 恢复定位           | 最新用户动作＞有效显式锚点＞历史进度＞起点。HTML5 与 IFrame 共用逻辑；迟到历史响应不得覆盖用户选择。无效／失效锚点不自动套用旧时间。                                       |
| 增强释义           | 新增可选 `subtitle_id`；校验视频归属、可见性与既有解锁资格，使用数据库原句；兼容无来源旧调用。来源失效／不匹配返回明确错误。                                               |
| 收词               | 沿用已有字段；提供 subtitle_id 时同样校验，并用数据库原句保存，拒绝错误关联。                                                                                              |
| 提示来源           | 可选 `note_scope` 为 `video`、`general` 或 null。现有缓存仍是视频＋词级，界面显示「视频用法提示／通用用法提示」，不冒称本句专属释义，无新增实时 AI 调用。                  |

浏览器关闭属于尽力保存；强杀进程或断网不能保证最后一次写入。站内离开时队列留出有限时间继续提交，不用本地状态伪装服务器确认。多设备同时观看的意图排序未新增承诺，以服务器最后确认位置为准。

## 已取消能力

- 移除观看录音、跟读、回放、波形比较、评分入口、录音权限请求，以及旧引导和结束积累流程；练习生成不再产生 sentence_repeat，保留现有选择、拼写与语境填空。
- 移除热力图、成就、周报入口和组件调用；词单完成不再弹成就卡，也不再写 celebrated_at。筛词完成、词汇每日计数、基本记录、掌握趋势与复习链路保留。
- 跟读、录音上传、热力图、成就、周报和词单成就旧 URL 保留鉴权兼容入口，统一 `410 / FEATURE_RETIRED`。旧周报页面跳转个人中心并显示下线说明。
- 删除周报 beat 调度；已入队的同名任务执行为空操作。停止成就授予、断签催促和相关通知生产；自愿开启的到期词汇提醒及账号／系统通知保留。
- 通知列表、未读计数共同排除已下线类型；兼容偏好不能重新启用。WebSocket 投递层也过滤旧 worker 的过期类型，避免列表没有消息却出现角标。
- 历史表、录音文件、账号导出、注销清理和历史媒体私有权限保留；没有数据迁移、批量历史清理或线上写入。首页、引导、购买页介绍和政策说明仅同步失效功能文案，权益价格、支付校验与访问资格未改。

- 前端：`npx playwright test e2e/watch-baseline-mobile.spec.ts e2e/watch-desktop-stage.spec.ts --workers=2 --retries=0`。本地前后端已启动时按现有配置复用；隔离 API 的测试本身不需要真实账号。

- 既有移动端回归：先启动本地前端 :3000，确保 :8000 空闲；`backend/` 运行 `.venv/Scripts/python.exe scripts/test_watch_mobile.py --node <Node绝对路径>`。使用随机临时数据库、测试 JWT、可播放合成媒体，启动测试 API 后顺序跑 `mobile-*.spec.ts`，最后关闭该 API 并删除专用库。不会替换已有 API，不发送短信。
