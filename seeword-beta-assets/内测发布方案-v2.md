> 与 v1（`内测发布方案.md`）差异：福利口径改为**内测期全功能免费**（不引入 Pro / 兑换码）；功能卖点更新为**批量收词、快速过筛、考纲词标注**；海报发布时点以功能开发完成为准。

---

## 一、内测定位与目标

- **定位**：种子用户内测 = 真实朋友体验 + 收集反馈 + 早期口碑。不发"广告"，发"朋友做了一个东西，想请你试试"。
- **周期**：暂定一个月，**截至 2026-10-19**（海报已写明）。
- **目标**：邀请 50 名左右真实用户注册，回收 ≥20 条有效反馈，验证「看视频 → 批量收词 → 快速过筛 → 掌握」学习闭环。
- **核心抓手**：专属感（首批名额）+ 即时利益（**内测期注册即全功能免费**）+ 反馈闭环（有效反馈换正式上线后权益）。

> ⚠️ 发布前提：**批量收词、快速过筛功能开发完成并可用后**，再发 Day2 正式邀请海报；功能未上线前只发 Day1 悬念预热。

---

## 二、玩法创意（任选 2–3 个先跑）

1. **首批名额制**：海报二维码直达注册页（`seeword.top/register?ref=moments`），文案强调"首批名额"，制造专属感；想做来源追踪可私发带备注的邀请链接。
2. **7 天打卡挑战**："连续 7 天，每天看 1 个视频 + 过筛 1 个词汇集合"，完成截图发群，奖励**创始成员徽章**（正式上线后保留）。
3. **反馈换权益**：提交有效 bug / 建议（内测群接龙或在线文档收集），每条合格反馈兑换**正式上线后会员时长**，上不封顶。
4. **"这个视频的词我全会了"传播梗**：把集合 100% 掌握的进度截图发朋友圈，配一句"刷完一集剧，顺手拿下 28 个四级词"——UGC 式传播。
5. **首批用户徽章**：内测用户专属"SeeWord 创始成员"称号 / 徽章，正式上线保留，制造身份感。
6. **内测群运营**：建 20–50 人小群，每天发"今日推荐视频 / 每日一词"、答疑、收集反馈，让用户互相看见进度。

| Day2 | 正式邀请 | poster_square.png / poster_v2.png | "我的产品 SeeWord 内测啦——看视频学单词，一个视频的考纲词一键全收进词汇本，会的划走、不会的拎出来学，刷完视频词也记住了。内测期全功能免费，扫码就能进，首批名额。" |
| Day3 | 功能演示 | 批量收词 / 过筛界面真实截图或录屏 | "看一个视频，点一下，里面所有四级词自动进词汇本；过一遍，会的划走、不会的单独学。演示一下 ↓" |
| Day4 | 真实反馈 | 内测用户反馈 / 打卡截图 | "内测第 3 天，有人已经连续打卡了。收到最有用的一条反馈是……" |

> 原则：每贴只说一件事；正文 1–3 句；不刷屏（一天最多 1 条）；配图为主、文字为辅。

## 四、转化路径

```
扫码（seeword.top/register?ref=moments）
  → 注册即全功能免费（内测期，至 2026-10-19）
  → 引导看第一个热门视频 → 点「+ 加入学习」体验批量收词
  → 进内测群
  → 反馈 / 打卡 → 创始成员徽章 / 正式上线后权益
```

- 无落地页，二维码直达注册页；产品介绍职责由海报承担。
- 内测期不出现 Pro / 兑换码 / 付费引导。
