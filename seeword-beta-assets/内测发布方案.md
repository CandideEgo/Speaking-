# SeeWord 朋友圈内测发布方案

> 配套物料：`seeword-beta-assets/`（主海报 poster_final.png、预热单图 teaser.png、og-image 已替换 `frontend/public/og-image.png`）

---

## 一、内测定位与目标

- **定位**：种子用户内测 = 真实朋友体验 + 收集反馈 + 早期口碑。不发"广告"，发"朋友做了一个东西，想请你试试"。
- **目标**：2 周内邀请 30–50 名真实用户注册，回收 ≥20 条有效反馈，完成 7 天打卡挑战 ≥10 人。
- **核心抓手**：专属感（内测名额/邀请码）+ 即时利益（注册 3 天试用 + 兑换码 30 天 Pro）+ 反馈闭环（有效反馈换 Pro 天数）。

---

## 二、玩法创意（可叠加，任选 2–3 个先跑）

1. **专属邀请码制**：每码对应一个朋友，码即"入场券"。码上可备注朋友昵称（如 SEEWORD-LIANG），核销时在后台能追踪来源。
2. **7 天打卡挑战**："连续 7 天，每天看 1 个视频 + 复习 5 个单词"，完成截图发群，送 30 天 Pro（或延长）。周报页的分享卡天然是打卡素材。
3. **反馈换时长**：提交有效 bug/建议（进内测群接龙或腾讯文档收集），每条合格反馈 +3 天 Pro，上不封顶。
4. **"我居然错了 X 次"传播梗**：把真实错题/词卡截图发朋友圈，配一句"这词我错了 4 次，终于记住了"——UGC 式传播，别人会好奇是什么 App。
5. **首批用户徽章**：内测用户专属称号/徽章（App 已有里程碑体系，可加"SeeWord 创始成员"），后续正式上线时保留，制造身份感。
6. **词汇量小测试钩子**（可选）：先发一张"测测你的词汇量"互动图，评论区报数，再引流到 App 内真实测词。
7. **内测群运营**：建 20–30 人小群，每天发"每日一词"、答疑、收集反馈，让内测用户互相看见进度，形成氛围。

---

## 三、7 天发布节奏

| 天 | 动作 | 配图/素材 | 文案方向（第一人称，熟人感） |
|----|------|-----------|------------------------------|
| Day1 | 悬念预热 | 预热单图（单词背了又忘？） | "最近废寝忘食搞了个小东西，能让刷视频顺手把单词记了。还在打磨，想找几个朋友先试试。" |
| Day2 | 正式邀请 | 主海报（扫码开启内测） | "我的第一款产品 SeeWord 内测啦——粘贴视频链接，AI 生成双语字幕，考纲词自动高亮，刷完视频单词也记住了。首批名额有限，私信我拿邀请码。" |
| Day3 | 功能演示 | App 截图/录屏（双语字幕+词卡） | 发 1 张真实界面截图 + "看《老友记》顺手学了 20 个词，词卡长这样。" |
| Day4 | 真实反馈 | 内测用户反馈/打卡截图 | "内测第 3 天，有人已经打了 3 天卡了。收到最有用的反馈是……" |
| Day5 | 打卡挑战 | 挑战海报（可复用主海报改文案） | "发起一个 7 天挑战：连续 7 天每天看 1 个视频+复习 5 个词，完成的送 30 天 Pro。想一起的评论区举手。" |
| Day6 | 学习日常 | 词卡/错题场景图 | 发一张真实词卡或"今天学到：actually 不只是'实际上'" |
| Day7 | 战报+二波 | 数据小结（注册数/打卡数）+ 新一批码 | "内测一周小结：X 人注册、X 人完成打卡、收到 X 条反馈，全改了。第二波邀请码已备好，还没上车的来。" |

> 原则：每贴只说一件事；正文 1–3 句；不刷屏（一天最多 1 条）；配图为主、文字为辅。

## 四、转化路径

```
扫码/点链接(seeword.top/register)
  → 注册即领 3 天试用
  → 兑换码升级 30 天 Pro（海报二维码指向注册页，邀请码单独私发）
  → 进内测群
  → 反馈/打卡 → 续码 → 口碑
```

- 二维码已合成进主海报，指向 `https://seeword.top/register?ref=moments`。
- 邀请码建议与海报分开私发（制造一对一专属感，也能追踪核销来源）。

## 五、验收指标（内测结束复盘用）

| 指标 | 目标 |
|------|------|
| 注册数 | 30–50 |
| 3 天留存（次日/3 日打开率） | ≥40% / ≥25% |
| 兑换码核销数 | ≥20 |
| 有效反馈条数 | ≥20 |
| 7 天打卡完成人数 | ≥10 |
| 主动转发/安利（朋友圈晒卡） | ≥5 |
