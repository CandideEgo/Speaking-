## 5. 接口设计（唯一新增的架构面）

```
MainLayoutInner
└─ <WatchChromeProvider>                       ← 新增：页面 ↔ 壳 的唯一接口
    ├─ {isWatch ? <WatchTopBar/> : <TopBar/>}
    ├─ <main id="main-scroll">…</main>
    └─ {isWatch ? <WatchBottomBar/> : <MobileTabBar/>}   ← 同一个槽位
```

- **判定用 `pathname.startsWith("/watch/")` + `isMobile`**，不等页面挂载 → 不会闪一帧旧顶栏。桌面端 `isWatch=false`，一切照旧。
- 页面通过 `useWatchChrome({...})`（effect 发布）给壳：`{ title, levelText, levelSelector, onBack }` 与播放句柄 `{ videoRef, isPlaying, toggle, prevSentence, nextSentence, openShadowing, shadowingActive }`。
- **进度条绝不用 React state 驱动**：`currentTime` 每秒跳 4 次，进 state 会让整个壳每秒重渲染 4 次。`WatchBottomBar` 内部 `requestAnimationFrame` 直读 `videoRef.current.currentTime`，只写那一根 2px 条的 `style.width`（DOM 直改，不进 state）。
- `WatchChromeProvider` 的默认值 = 空 chrome，所以任何页面不发布也不会崩（`TopBar`/`MobileTabBar` 正常渲染）。

## 10. 本地怎么跑

```bash
# 栈（Windows；后端必须带 PYTHONUTF8）
cd backend  && PYTHONUTF8=1 ./.venv/Scripts/python.exe -m uvicorn app.main:app --port 8000
cd frontend && npm run dev                       # :3000，Next dev 默认监听 0.0.0.0

# 门
python scripts/check-knowledge/check_knowledge.py          # 2.3s，七项必须全 [ok]
cd frontend && npx tsc --noEmit && npm run lint

# 移动端 e2e（必须从 frontend/ 跑，playwright 在它的 node_modules 里）
cd frontend && npx playwright test --project=chromium \
  mobile-inline-subtitle mobile-pip-scroll mobile-player-shell \
  mobile-wordcard-drawer viewport-height mobile-watch-chrome
```

**已知坑**（都在 `knowledge/wiki/guides/release-checklist.md`，这里只列会咬人的）：

- `playwright` 从仓库根跑会 `ERR_MODULE_NOT_FOUND` —— 必须 `cd frontend`；
- 「播放中」类断言要求 `backend/media/<video-id>.mp4` 是**真文件**；本机 dev 库里那支 `E2E Demo Video` 的 mp4 是真的（60 MB），可用；
- 本地全量 e2e 会被 `/auth/sms/register` 的 3/minute 打脸（429）：用 `ENV=testing` 起后端，或先清 `LIMITS:LIMITER/127.0.0.1//api/v1/auth/sms/*`；
- 后端 Windows 下不带 `PYTHONUTF8=1` 会在读 `.env` 时 `UnicodeDecodeError`（GBK）；
- 别用 `npm install` 不带 `--legacy-peer-deps`（eslint 10 vs eslint-plugin-react-hooks 的既有冲突）；
- **`git push` 走本地代理**（`http.proxy = http://127.0.0.1:7897`）：代理没开时报 `Failed to connect to github.com port 443 via 127.0.0.1`，绕过即可 —— `git -c http.proxy= -c https.proxy= push origin master`（2026-10-02 实测）。
