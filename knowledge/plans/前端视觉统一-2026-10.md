## 二、拍板：A（全站单容器）

**决定**：全站收敛到**一个容器** `.container-page`（`max-w-page` 1320 / `px-4 sm:px-7`）；
容器**归壳层所有**（`MainLayoutInner` 渲染一次，页面不再写容器类），`TopBar` 的行内内容共用同一个类。
删 `.container-wide` 与 `--max-width-wide`，并清掉页面级 `max-w-3xl` / `max-w-[880px]` 覆盖。

**为什么 A 站得住**（三条都是事实，不是偏好）：

1. **线上本来就是 1320。** 生产跑的镜像来自 10-04 的构建，而 S2（10-08）才引入 2400 —— 所以线上今天
   全站单宽 1320。选 A 等于把本地宽度**恢复到与线上一致**，「本地 vs 线上」这条分歧随之消失。
2. **四级宽度本身就是症状。** 收成一级后，`TopBar` 与内容左右边界对齐变成构造结果，不需要规则去维持。
3. **A 严格优于线上。** 线上顶栏是满宽的（S2 之前没有 `.container-wide`），所以线上在 2560 屏上
   **顶栏与内容也错位**；A 把顶栏并入同一个容器，顺手把线上这个缺陷一起修掉。

**照账接受的代价**（「默认翻转 / 行为移除」必问 #2 的答案）：

- 2560 屏两侧各留 ~620px；S2 的「内容铺满」与 S6 的 8 列作废，回到 1320 内约 4 列 × 292px。
  **S2/S6 那两轮的收益归零** —— 这是本次选择里最贵的一项。
- 页面级读宽覆盖被移除后，`practice/daily` / `notifications` / `contact` 的正文行宽会变长；
  正文类区块改用一个 `--measure` 读宽 token（§4.4）。
- 宽屏用户会感到「内容变小」；这是显式的可见回退，用户已确认接受。

## 三、目标态

1. **一个容器**：`.container-page` 唯一；页面无容器类；`TopBar` 共用。
2. **一个页头**：`ui/PageHeader` 唯一；`app/**/page.tsx` 不自写 `<h1`。
3. **一套 token**：圆角 3 档、字号 6 档、品牌橙 1 个名字、面/文字别名各留一组。
4. **一个卡片**：卡片面走 `ui/Card`（或其分组包装 `admin/SectionCard`），页面不拼面。
5. **globals.css 只放跨页面的类**：页面专属类回到各自组件。
6. **一条机器检查**：上面 1–5 里可机械判定的部分进 `npm run check`。

## 四、目标尺度（本方案唯一的「审美」部分，其余都是枚举）

### 4.1 圆角：3 档 + 2 个特殊

| token | 值 | 用途 | 旧档合并 |
|---|---|---|---|
| `--radius-sm` | 6px | 内嵌小块、输入、分段控件内段 | `xs 4`、`sm 8` |
| `--radius-md` | 10px | **卡片与面板的默认** | 默认 `12`、`md 10` |
| `--radius-lg` | 16px | 大容器、弹层、抽屉 | `lg 16`、`xl 22`、`2xl 24` |
| `rounded-full` | — | 圆、头像、圆形按钮（保留） | — |
| `rounded-pill` | — | 整宽药丸 / 分段控件外壳（保留） | — |

### 4.2 字号：6 档 + 3 个 display（营销页专用，保留现值）

| token | 值 | 用途 |
|---|---|---|
| `text-caption` | 11px | 角标 |
| `text-meta` | 12px | 标签、元信息 |
| `text-body` | 14px | **正文默认；移动端正文下限不动**（DEC-073 的刻度） |
| `text-body-lg` | 16px | 强调正文、列表主行 |
| `text-title` | 20px | 区块标题、卡片标题 |
| `text-display` | 28px | 页面标题（`PageHeader` 的 title） |

映射（把 11 个手写 px 与 Tailwind 默认档收进上表）：`10→11`、`13→14`、`15→14 或 16`、`17→16`、
`18→20`、`22→20`、`24→28`（页标题）、`26→28`、`28→28`、`34→28`；
Tailwind `xs 12 / sm 14 / base 16 / lg 18 / xl 20 / 2xl 24` 逐档对应到
`meta / body / body-lg / body-lg / title / display`。`text-3xl(30)` 与 `text-4xl(36)` 只允许出现在 `.display-*`。

### 4.3 颜色名：一名一义

- 品牌橙唯一名 `brand-*`；删 `primary` / `primary-active` / `primary-disabled` / `coral` /
  `coral-active` / `coral-soft` / `terracotta`。
- 面唯一组 `canvas / surface-soft / surface-card / surface-cream-strong`；删 `cream` / `cream-soft` /
  `cream-card` / `cream-strong` / `parchment` / `ivory` / `olive` / `olive-soft`。
- 深面唯一组 `surface-dark / surface-dark-elevated / surface-dark-soft`；删 `navy` / `navy-elevated`。
- 文字唯一组 `ink / body / body-strong / muted / muted-soft`；删 `muted-foreground` /
  `muted-foreground-var` / `foreground`。
- 语义 `success / warning / error`；删 `danger`。`on-primary` / `on-dark` / `on-dark-soft` 保留。
- **`.tsx` 里禁止原始调色板工具类**（INV-017 的机械版）。考试词高亮的 `bg-*-50` 表移进
  `lib/examLevels.ts` 的 token 映射，作为显式白名单，不在组件里裸写。

### 4.4 读宽

正文类区块（通知、联系我们、条款、真题文章）用一个 token `--measure`（默认 `68ch`），
**页面容器仍是 1320**。读宽是内容属性，不是容器属性 —— 这是 A 与「每页一个 max-w」的区别。

### P4 · 字号刻度收敛

1. 按 §4.2 映射替换 19 档字号；手写 px 全部消失。
2. **保留**移动端正文 ≥14px（DEC-073）与 `.now-sub-en` / `.now-sub-zh` **行内 style 是唯一字号来源**

**验收**：`rg "text-\[[0-9]+px\]"` 只剩允许的 display 类；跑全部 `mobile-*.spec.ts`

## 六、硬边界（每一片都适用，破一条即该片作废）

- **gutter `px-4 sm:px-7` 一个字不改。** 播放页画框与当前句卡靠 `-mx-4 sm:-mx-7` 精确抵消容器 padding
  实现全出血；容器 padding 一改，**640–1023px 档就错位、横向溢出，而那一档没有任何 e2e 兜底**
  （S2 方案 §3.1 的硬约束，原文如此）。
- **`isMobile`（≤1023px）分支的几何零改动**；INV-019 / 020 / 021 / 022 / 023 / 024 / 025 是红线；
  改 `components/watch/**` 的移动端路径前先读这七条。
- **播放页桌面版式不动**：`.watch-stage-cap`、右栏 `lg:grid-cols-[minmax(0,1fr)_minmax(360px,420px)]`、
  字幕自动居中那段 `scrollIntoView` 逻辑（BUG-08 整条撤销，改动会白屏）。
- **INV-004**：不建 `tailwind.config.js`；新类写 `globals.css` 的 `@layer components`。
- **INV-017**：颜色走语义 token。
- **`.now-sub-en` / `.now-sub-zh` 的字号与行高只能来自行内 `style`**（INV-021）。
- 删除零引用组件前先 `rg` 证明零引用（本仓判据：全仓 grep 只有定义行）。
