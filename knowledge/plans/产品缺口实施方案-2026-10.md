## 一、P0：入口漏斗

### P0-A 免密注册/登录

- 后端主流程统一到「验证码即注册/登录」：`POST /auth/sms/login` 扩展为登录+注册一体，
  验证码通过后不存在即建号（`hashed_password` 保持 NULL），响应新增 `is_new_user: bool`。
  `/auth/sms/register` 保留一个发布周期做兼容，`password` 改可选并标记废弃。
- `send-code` 的 `purpose` 统一为 `auth`，服务端在 `auth` 下同时接受登录与注册；
  旧 `register` / `reset_password` 保留兼容。
- `/auth/sms/login` 保留既有 10/min 限流；新号建号沿用 3/min 级别的注册风控与
  `registration_enabled` 开关。
- 后置设密码复用 `POST /auth/change-password`：`hashed_password` 为空时允许不传旧密码
  直接设置，且**不**失效当前会话（首设非改密，不更新 `password_changed_at` 的会话失效语义）。
- 前端：`register/page.tsx` 改为「手机号 + 验证码」两步，成功后直接进 onboarding，
  去掉密码与强度校验；`login/page.tsx` 增加「验证码登录」tab，保留手机号+密码；
  密码设置/修改入口移到「我的 → 账号安全」，忘记密码沿用 `/forgot-password`。

### P0-B 新用户第一课（真实视频 + `is_demo`）

- 复用现有 `Video.is_demo` 与管理员开关，不再制作专用视频、不新建首课系统。
  后端保证全局至多一条 `is_demo=true`：管理员置真时自动清其余。
- 新增 `GET /videos/demo`（登录态）返回该视频摘要；无标记时返回 404。
  注册/onboarding 完成后的 `next` 指向 demo watch 页；404 时回退首页并记一条埋点，不阻塞。
- 首课引导复用 `useCoachMark`：进入 watch 首次触发「点词 → 看释义 → 跟读」最短闭环；
  进入/点词/跟读/完成写入 `behavior_events`。

### P0-C 考试定位与文案收窄

- 对外统一为「视频词汇 + 阅读训练」；`exam_service` 维持 `reading_A/B/C`。
- 清理登录/首页/定价/条款/海报中的听力与全科四六级暗示；「听力」仅作为词汇题类型保留。
- 同步 `requirements/REQUIREMENTS.md` 与 PRD 相关章节，并立一条决策记录。

## 二、P1：一致性与闭环

### P1-1 onboarding 单一真相源

- `users.onboarding_completed` 为唯一真相源，删除前端 localStorage 镜像的判定作用；
  路由是否进 onboarding 以 `/users/me` 为准。
- `MainLayoutInner` 在拿到用户前渲染 loading 骨架，不再先渲染首页再跳转，消除闪首页。
- 跳过改为显式代价提示（说明会关闭考试词高亮），并提供「去设置目标」直达；
  在首页、播放页、「我的」设置处固定「设置目标考试」入口，设置后立即刷新高亮。

### P1-2 通知跨 worker 可靠化

- `notifications.py` 的模块级 `ws_manager` 广播改走 Redis Pub/Sub：各 worker 订阅统一
  channel，收到后投递给本进程 socket；保留本地直投，Redis 不可用按 INV-002 fail-open
  （落库成功、仅放弃实时推送）。可对照 `presence.py` 的既有 Redis 用法。
- 前端 `NotificationDropdown` 在 WS 已连接时也保留低频兜底轮询（如 120s），
  断开时回到 30s；unread-count 与列表都兜底，避免跨 worker 通知被静默丢弃。
- 短信/微信提醒只在方案与知识层登记为后续扩展，不进本轮实现与承诺。

### P1-3 词卡锚点下移（修订 INV-022）

- `useSheetGeometry` 把词卡/抽屉锚点从画框下沿改为**当前句卡下沿**，词卡只覆盖后续文稿；
  画框与当前句卡几何不动。
- INV-022 的「词卡完整盖住当前句」由已接受代价改判为不允许；同步更新移动端
  `mobile-wordcard-drawer.spec.ts` 几何断言并做真机复看。

### P1-4 两端导航统一

- 桌面 TopBar 与移动 TabBar 统一为：**首页 / 频道 / 练习 / 词汇 / 我的**
  （顺序、文案、高亮一致）。桌面补「我的」，移动文案对齐「练习 / 词汇」。
- 学习记录、收藏、设置归入「我的」页/二级；榜单、周报、通知、兑换、定价作为二级入口，
  明确「二级功能不占主干」。

### P1-5 答对自动前进 + 统一进度语义

- `user_preferences` 新增 `auto_advance_on_correct: bool default false`
  （独立列，复用 preferences 的 GET/PUT）。
- 词汇训练提供持久化开关；开启后答对约 800ms 自动前进，答错保持手动
  （沿用 `PracticePanels` 已有语义）。开关不改变既有默认行为。
- 训练头部进度统一为「本轮 done/total」，去掉并存的「第 N 题」；
  这是行为变更，需决策记录。

### P1-6 集合闭环庆祝与成就卡

- 由 `vocab_set_service` 闭环事件（`learned_words` 且 metadata 含 `set_id`）驱动一次庆祝，
  不扩展「每用户每类型一次」的 `UserMilestone`。
- 闭环响应或幂等端点（`POST /vocab-sets/{id}/celebrate`，按 `set_id` 幂等）返回卡片数据；
  分享复用周报 Canvas 生成可保存 PNG。

### P1-7 30 天可撤回注销 + 异步数据导出

- `users` 新增 `deletion_requested_at`、`deletion_scheduled_at`、`deletion_reason`（可选）。
- 端点：`POST /users/me/deletion`（二次确认，返回 `scheduled_at = now + 30d`，幂等）、
  `DELETE /users/me/deletion`（撤销并清空字段）、`GET /users/me/export`
  （建任务返回 task_id/status）、`GET /users/me/export/{task_id}`
  （状态 + 一次性短时下载 URL，如 15 分钟）。
- 冷静期内**允许登录**；登录后顶部/「我的」持续显示「账户将于 X 天删除」横幅与显式
  「撤销注销」按钮，不在登录时自动取消。
- Celery 每日清理任务处理到期账号：删除个人数据与用户自产媒体（头像、跟读录音、上传），
  `behavior_events.user_id` 置 NULL 保留匿名统计，**手机号在删除完成后才释放**
  （防止绕过封禁/重复领取试用）。
- 导出包为 ZIP：结构化 JSON + CSV（资料、词汇、跟读记录、学习记录、通知偏好、行为事件），
  **含头像与跟读录音原件**；任务完成通过站内通知告知；失败重试并通知；
  账号删除后导出包一并清理。

### P1-8 上线前清理

- `contact/page.tsx` 私人 QQ 邮箱改为域名邮箱/工单入口；复查 terms/privacy/pricing 的
  隐私与付费表述；搜索占位符去掉并不存在的「单词」搜索（取收窄文案，不新增词汇搜索）。
