## 1. 这一段要解决什么

- 问题：站外提醒、考试目标叙事、内测权益迁移、内测运营和结构性 P2 仍是「只登记、未拍板」，
  后续会话不知道它们是继续不做、改为做，还是应当拆成独立工作流。
- 可观察结果：每个延后项都有一条决策，或一条带复议条件和负责人的明确挂起记录。
- 不做什么：不在本切片里直接实现功能；不把「已登记」写成「已决策」；不扩张本轮 P0/P1 范围。

## 2. 边界与契约

- 涉及议题：
  - A1 / F5 站外提醒；
  - A5 / F2 考试目标叙事；
  - A6 内测权益迁移；
  - F4 内测运营机制产品化；
  - B1/B2/B3/B4/B5/C1/C2/C4/D1/D2/F6 结构性 P2。
- 会改的契约：台账、计划索引和决策记录；具体实现若被拍板，另开切片和 Issue。
- 开工前必须确认：产品负责人、预算/时间边界、是否允许本轮插队。

## 3. 执行路径

1. 从 [产品缺口总结](../../../plans/产品缺口-2026-10.md) 的闭环状态表提取每个未闭环/部分项。
2. 对每项写成最小决策包：问题、现状、选项、代价、建议、复议条件。
3. 能拍板的追加决策并更新索引；不能拍板的写成显式 defer，指定负责人和复议触发条件。
4. 更新总纲仪表盘与相关计划文件；不为每个决策自动创建实现票，除非实现了切片的验收条件。

## 4. 验收与证据

- 机械验收：决策条目与索引一致；文档链接有效。
- 行为验收：每个延后项都有明确处置，不再以「见后续」结束。
- 证据位置：本文件 §5，列出决策 ID / defer 结论和对应文件。
- 回退方式：决策只追加，不回改历史；如需改变结论，追加新决策并标注旧决策。
