# Plan — S01–S05 切片推进

> WorkItem：`W-20261014-01`

## 执行顺序

1. **S02 前端测试载体**：先决定组件级测试或 e2e 的唯一路线，保证后续行为有验收入口。
2. **S01 服务环境验收**：环境恢复后按迁移、清理、导出、通知、真实媒体 e2e、完整门禁顺序执行。

S01 与 S03 已阻塞，S05 明确 deferred；S02 和 S04 是当前可处理前沿。Issue 创建后，以 GitHub
的原生依赖和状态覆盖此处的排序快照。
